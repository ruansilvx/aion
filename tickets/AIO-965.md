# **T1** — Create `lib/core/markdown/wikilink_extractor.dart`:

`WikilinkMatch` (`{required String raw, required String target,
String? alias}`) and `WikilinkExtractor` (`abstract final class`)
with static:
- `extractReferences(String content) -> List<WikilinkMatch>` (regex
`\[\[([^\[\]|]+)(?:\|([^\[\]]+))?\]\]`, `target`/`alias` trimmed,
deduplicated by `(target, alias)` pair, case-insensitive on
`target`, first-seen casing preserved).
- `looksLikeTicketId(String target) -> bool` — a pure syntactic check
(uppercase-letter prefix, hyphen, numeric suffix, e.g. `AIO-42`) for
whether `target` looks like a `Ticket.ticketId` rather than a title;
no lookup, just shape.
- `rewriteTitle(String content, String oldTitle, String newTitle) ->
String` — case-insensitive replace of every occurrence whose
**target** (not alias) equals `oldTitle`, covering both
`[[oldTitle]]` and `[[oldTitle|...]]`, leaving any id-anchored
occurrence (`[[TicketId...`) untouched since its target is never a
title. Returns `content` unchanged if nothing matches.
