# Design: trash-age-and-manual-purge

## Domain layer

`domain/repositories/ticket_repository.dart` — one new method on
`TicketRepository`:

```dart
/// Permanently deletes every currently trashed ticket whose `deletedAt`
/// is older than [age] (cascading to comments and `ticket_links`, same
/// as [emptyTrash]). Returns the number of tickets purged. No-op
/// (returns 0) if none are eligible.
///
/// Safe to filter per-ticket, with no cascade/subtree walk: trashing
/// always stamps a whole affected subtree with one `DateTime.now()` at
/// once (see [trashTickets]), and there is no UI path that re-trashes a
/// single already-trashed descendant independently — so every member of
/// a given trashed subtree always shares the same `deletedAt`. A root
/// and its descendants therefore always age out together.
Future<int> purgeTrashOlderThan(Duration age);
```

Placed directly below `emptyTrash()` in the interface, since it's the
same shape of operation (bulk irreversible delete over the trashed set)
with an added age filter.

## Data layer

`data/repositories/drift_ticket_repository.dart` — implementation
mirrors `emptyTrash()` almost exactly, adding an age filter over the
same `getTrashedTickets()` fetch:

```dart
@override
Future<int> purgeTrashOlderThan(Duration age) async {
  final cutoffMs = DateTime.now().subtract(age).millisecondsSinceEpoch;
  final trashed = await _db.ticketDao.getTrashedTickets();
  final ids = trashed
      .where((row) => row.deletedAt! < cutoffMs)
      .map((row) => row.id)
      .toList();
  if (ids.isEmpty) return 0;

  await _db.transaction(() async {
    await _db.commentDao.deleteCommentsForTickets(ids);
    await _db.ticketLinkDao.deleteLinksForTickets(ids);
    await _db.ticketDao.deleteTicketRows(ids);
  });
  return ids.length;
}
```

`row.deletedAt!` is safe to force-unwrap: `getTrashedTickets()`'s query
is `WHERE deleted_at IS NOT NULL`, so every row it returns already has a
non-null `deletedAt`. No new `TicketDao` methods are needed — this
reuses `getTrashedTickets()`, `deleteTicketRows()`, and the DAOs already
wired into `_db`, exactly as `emptyTrash()` does today.

## Core layer — relative-time formatting

New file `core/utils/relative_time_format.dart`, same shape as the
existing `core/utils/duration_format.dart` (a pure function, no
`BuildContext`, called directly from presentation-layer `Text` widgets
without going through `l10n` — matching the shipped precedent of
`formatDurationMinutes`, which is already rendered directly in
`ticket_detail_screen.dart` without an ARB entry):

```dart
/// Formats how long ago [deletedAt] happened as a short label prefixed
/// "Trashed " (e.g. `'Trashed today'`, `'Trashed yesterday'`,
/// `'Trashed 12 days ago'`, `'Trashed 3 weeks ago'`,
/// `'Trashed 2 months ago'`). [now] defaults to [DateTime.now] and only
/// exists as a parameter for deterministic tests.
String formatTrashedAge(DateTime deletedAt, {DateTime? now}) { ... }
```

Buckets: same calendar day → `'Trashed today'`; previous calendar day →
`'Trashed yesterday'`; `< 7` days → `'Trashed N days ago'`; `< 30` days →
`'Trashed N weeks ago'` (rounded down); `>= 30` days → `'Trashed N months
ago'` (rounded down, `days ~/ 30`). Exported from `core/core.dart`
alongside `duration_format.dart`.

## Presentation layer

### `TrashState` (`presentation/cubit/trash_state.dart`)

`TrashLoaded` gains a third field. Positional constructor, consistent
with its existing two-positional-arg shape:

```dart
class TrashLoaded extends TrashState {
  const TrashLoaded(this.tickets, this.descendantCounts, this.purgeEligibleCount);

  final List<Ticket> tickets;
  final Map<String, int> descendantCounts;

  /// How many currently trashed tickets (roots and descendants combined)
  /// are older than [TrashCubit.purgeAgeThreshold] — i.e. how many
  /// "Purge old" would remove right now. Drives the purge action's
  /// enabled state and its confirm-dialog count.
  final int purgeEligibleCount;

  @override
  List<Object?> get props => [tickets, descendantCounts, purgeEligibleCount];
}
```

Existing call sites that pattern-match `TrashLoaded(:final tickets,
:final descendantCounts)` (as `trash_screen.dart` already does) keep
compiling unchanged — Dart object-pattern destructuring doesn't require
naming every field. Existing positional-constructor call sites
(`TrashLoaded([], {})` in `trash_cubit_test.dart`) need a third argument
added.

### `TrashCubit` (`presentation/cubit/trash_cubit.dart`)

```dart
class TrashCubit extends Cubit<TrashState> {
  TrashCubit(this._repository) : super(const TrashLoading());
  final TicketRepository _repository;

  /// How old a trashed ticket must be before "Purge old" will remove it.
  /// Fixed, not user-configurable (see proposal.md's Non-goals).
  static const Duration purgeAgeThreshold = Duration(days: 30);

  Future<void> load() async {
    emit(const TrashLoading());
    try {
      final all = await _repository.getTrashedTickets();
      // ... existing root/descendantCounts reduction, unchanged ...
      final cutoff = DateTime.now().subtract(purgeAgeThreshold);
      final purgeEligibleCount =
          all.where((t) => t.deletedAt!.isBefore(cutoff)).length;

      emit(TrashLoaded(roots, descendantCounts, purgeEligibleCount));
    } catch (e) {
      emit(TrashError(e.toString()));
    }
  }

  // ... existing restore/permanentlyDelete/emptyTrash, unchanged ...

  /// Permanently deletes every trashed ticket older than
  /// [purgeAgeThreshold] via [TicketRepository.purgeTrashOlderThan],
  /// then reloads. Emits [TrashError] if the repository call throws.
  Future<void> purgeOldTrash() async {
    try {
      await _repository.purgeTrashOlderThan(purgeAgeThreshold);
      await load();
    } catch (e) {
      emit(TrashError(e.toString()));
    }
  }
}
```

`purgeEligibleCount` is computed from `all` (the full flat trashed list
`load()` already fetches) — no extra repository round-trip. This keeps
the count the cubit shows in sync with exactly what
`purgeTrashOlderThan` will remove, using the same threshold constant on
both sides.

### `TrashedTicketTile` (`presentation/widgets/trashed_ticket_tile.dart`)

Add the age label to the existing second `Row` (currently `TypeChip` +
optional "+N subtasks"), after the subtasks label:

```dart
Row(
  children: [
    TypeChip(type: ticket.type),
    if (descendantCount > 0) ...[
      const SizedBox(width: 9),
      Text('+$descendantCount subtasks', style: AionText.time.copyWith(color: c.textMuted)),
    ],
    const SizedBox(width: 9),
    Text(
      formatTrashedAge(ticket.deletedAt!),
      style: AionText.time.copyWith(color: c.textMuted),
    ),
  ],
),
```

`ticket.deletedAt!` is safe here for the same reason as the repository
change — every ticket reaching `TrashedTicketTile` came from
`TrashCubit.load()`'s `getTrashedTickets()` fetch, which only returns
tickets with a non-null `deletedAt`.

### `TrashScreen` (`presentation/screens/trash_screen.dart`)

New header action, `_PurgeOldAction`, styled identically to the
existing `_EmptyTrashAction` (bordered ghost button, danger-tinted icon
+ label, `Opacity` when disabled) but with its own icon
(`PhosphorIcons.clockCounterClockwiseLight`, to read distinctly from
`_EmptyTrashAction`'s `trashLight`) and label
(`context.l10n.ticketTrashPurgeOldAction`). Placed to the left of
`_EmptyTrashAction` in the header `Row`, both reading `TrashLoaded`'s
new `purgeEligibleCount`:

```
Row (header)
├─ _BackButton
├─ SizedBox(width: 13)
├─ Column [title, item-count subtitle]
├─ Spacer
├─ _PurgeOldAction(enabled: purgeEligibleCount > 0, onTap: ...)
├─ SizedBox(width: 8)
└─ _EmptyTrashAction(enabled: !isEmpty, onTap: ...)
```

`_PurgeOldAction`'s `onTap` reuses the existing
`_confirmPermanentDelete` helper already defined on `TrashScreen`
(same destructive-tone confirm dialog used by "Empty trash" and
per-row "Delete forever"):

```dart
_PurgeOldAction(
  enabled: purgeEligibleCount > 0,
  onTap: purgeEligibleCount == 0
      ? null
      : () => _confirmPermanentDelete(
          context,
          title: context.l10n.ticketTrashPurgeOldConfirmTitle,
          message: context.l10n.ticketTrashPurgeOldConfirmMessage(
            purgeEligibleCount,
            TrashCubit.purgeAgeThreshold.inDays,
          ),
          onConfirmed: () => context.read<TrashCubit>().purgeOldTrash(),
        ),
)
```

Both new `BlocBuilder`s needed here read `TrashLoaded.purgeEligibleCount`
the same way the existing header `BlocBuilder` already reads
`state.tickets.length`/`isEmpty` — no new `BlocBuilder` boundary
required, just widening what the existing header-row builder reads.

# Aion — Trash Age Indicator & Purge Old Specification

Implementation-ready spec for two additions to the existing `/tickets/trash` screen: (1) a per-row **age label** showing how long each ticket has been trashed, and (2) a **"Purge old"** header action that bulk-permanently-deletes everything trashed more than a fixed **30-day** threshold. No new screens or routes — this modifies `TrashedTicketTile` and the `TrashScreen` header only.

- **No Material widgets or types anywhere.** Build from Flutter primitives — `DecoratedBox`, `Container`, `GestureDetector`, `CustomPaint`, `Row`, `Column`, `Wrap`, `Padding`, `AnimatedScale`. Do **not** reference `Card`, `ElevatedButton`, `Scaffold`, `AppBar`, `ThemeData`, `ColorScheme`, `ListTile`, `SnackBar`, `InkWell`, or any other `material.dart` symbol.
- `c` = active `AionColors`; `a` = theme `fillAlpha` (Arctic `0.11` / Obsidian `0.16`); `isDark` = Obsidian.
- Both themes share one code path; only token values differ. Where a component is identical across themes it is stated explicitly.
- Translucent fills are `token.withOpacity(x)` — never hardcoded ARGB.
- Companion mockups: `Aion Ticket Trash Age and Purge Mockups.dc.html` — Trash screen `1a`, purge confirm dialog `2a`, component states `3a` (Arctic + Obsidian throughout).
- Base components this builds on: `TrashedTicketTile` and `TrashScreen` header from `Aion Ticket Trash and Bulk Delete Spec.md` §7–8. Copy shapes/paddings from there; only the additions below are new.

## 0. New tokens

No new colors, radii, or spacing. Everything resolves to existing tokens.

- Age-label text uses the existing **`AionText.time`** style (JetBrains Mono, 11, w400) — the same token already used by the tile's `"+N subtasks"` label — colored **`c.textMuted`**.
- The "Purge old" button reuses the existing ghost-button geometry and the `c.danger` family already used by "Empty trash".

One implementation constant (not a design token):

```dart
const Duration kPurgeThreshold = Duration(days: 30); // "old" = trashed more than 30 days ago
```

## 1. Age label (addition to `TrashedTicketTile`)

A read-only monospace label appended to the tile's **line 2** (the type-chip row), stating how long the ticket has been in Trash. Deliberately identical in weight/color to the existing `"+N subtasks"` label so the two read as one metadata run.

### 1.1 Placement & layout

- Added to `TrashedTicketTile` line 2 (`TrashedTicketTile` §8.1 of the base spec), **after** the `"+N subtasks"` label — or directly after the type chip when there is no subtasks label.
- **Change line 2 from `Row` to `Wrap`** so the age label reflows to a second visual line when the row is crowded (type chip + subtasks + age exceed the content width). This is the overflow behavior — see §1.4.

```
Wrap(
  spacing: 9,        // AionSpacing-ish; matches existing 9px gap on line 2
  runSpacing: 6,     // vertical gap when the age label wraps to a new run
  crossAxisAlignment: WrapCrossAlignment.center,
  children: [ TypeChip, if (hasSubtasks) SubtasksLabel, AgeLabel ],
)
```

- Line 2 sits `8px` below line 1 (unchanged from base spec §8.1).

### 1.2 Text style & color

| Property | Value |
|---|---|
| Text style | `AionText.time` → `.copyWith(color: c.textMuted)` |
| Font | JetBrains Mono, 11, w400 (from `AionText.time`) |
| Color | `c.textMuted` (Arctic `#8496A6` / Obsidian `#6B7690`) |
| maxLines | `1` (the string is always short; never ellipsized in practice) |

**Confirmed:** this matches the `"+N subtasks"` label exactly (same style token, same color). Do **not** give it its own color or an icon — it is plain text.

### 1.3 Copy / bucketing

Computed from `now - trashedAt`. Use these buckets (all prefixed `"Trashed "`):

| Elapsed | Label |
|---|---|
| < 1 day (same calendar day) | `Trashed today` |
| 1 day | `Trashed yesterday` |
| 2–6 days | `Trashed {n} days ago` |
| 7–13 days | `Trashed {n} days ago` |
| 14–29 days | `Trashed {n} weeks ago` (`n = elapsed ~/ 7`) |
| 30–59 days | `Trashed 1 month ago` |
| 60+ days | `Trashed {n} months ago` (`n = elapsed ~/ 30`) |

- Singular/plural correctly (`1 day ago` never appears — that bucket is `yesterday`; `1 week`/`1 month` are singular).
- Weeks kick in at 14 days so `"Trashed 12 days ago"` still reads in days (see mockup `1a` row 4).

### 1.4 Overflow / crowded behavior

- With the `Wrap` (§1.1), when `id badge + title` (line 1) and `type chip + "+N subtasks" + age` (line 2) can't all fit, the **age label wraps to its own run below the chip+subtasks** — it never truncates or clips. See mockup `1a` rows AIO-103 (`+3 subtasks` · `Trashed 12 days ago`) and AIO-64 (`+6 subtasks` · `Trashed 3 weeks ago`).
- Line 1's **title** keeps its existing `maxLines: 1` + ellipsis; the age/subtasks metadata is never allowed to push the title.
- Never let the age label steal width from the type chip: chip and subtasks label are `WrapCrossAlignment.center` intrinsic-width children; the age label is simply the last child and wraps last.

### 1.5 Theme note

**Identical in both themes** — it is a muted monospace text label; only the `textMuted` token value differs (Arctic `#8496A6` / Obsidian `#6B7690`). No structural difference.

## 2. "Purge old" header action (new component, `TrashScreen` header)

A second bulk action in the Trash header, alongside the existing "Empty trash" button. It opens the destructive confirm dialog (§3) and then permanently deletes every ticket trashed more than `kPurgeThreshold` (30 days) ago. A **bordered ghost button** matching "Empty trash" exactly, differing only in icon and label.

### 2.0 Geometry (shared by all states)

| Property | Value |
|---|---|
| Shape | ghost/outlined — transparent fill by default, `1px` border |
| Padding | `EdgeInsets.symmetric(horizontal: 12, vertical: 8)` |
| Radius | `AionRadius.md` (10) |
| Border | `1px c.border` (default) |
| Content | `Row(mainAxisSize: min, gap: 6)` — icon + label |
| Icon | Phosphor **`clock-counter-clockwise`** (thin-line, 1.5px stroke), **14px** |
| Label | `"Purge old"`, `AionText.button` sized at **12.5px w700** (matches "Empty trash") |
| Icon + label color | `c.danger` (destructive family, but ghost-bordered — not a filled danger button) |
| Shadow | none |

Icon rationale: a clock-with-reverse-arrow (history) glyph reads as an **age-based** action, visually distinct from "Empty trash"'s trash-can glyph (delete-everything). Never reuse the trash-can here.

### 2.1 Placement in the header row

- Sits **immediately to the left of "Empty trash"**, `8px` (`AionSpacing.sp8`) gap between the two.
- The pair is right-aligned in the header's trailing cluster (`Spacer` before them).
- **Layout refinement for the phone canvas (≤380 logical px):** the back button + title/count block already consume the top header row; placing two text-labelled ghost buttons on that same row overflows 380px. Put the two bulk actions on a **dedicated action sub-row directly beneath the title block**, right-aligned:

```
Header Column(gap: 12):
├─ Row(gap: 13): [Back 37×37] [Title "Trash" + "{n} items"] [Spacer]
└─ Row(gap: 8):  [Spacer] [Purge old] [Empty trash]
```

  On desktop-wide the same two buttons render inline-trailing on the title row (there is room); the sub-row is a mobile reflow only. Header padding `EdgeInsets.fromLTRB(20, 6, 20, 12)`; the action sub-row keeps the `8px` gap to the title block. See mockup `1a`.

## 4. Behavior (for implementers)

- **What "Purge old" deletes:** every trashed **root** whose `trashedAt` is older than `kPurgeThreshold`, together with its full structural subtree (same cascade as base spec §9). Roots younger than the threshold and their subtrees are untouched.
- **Disabled state source of truth:** the same predicate that enables the button (`§2.6`) drives both the button's enabled state and the `{n}` count shown in the dialog — compute once, pass to both.
- **Confirmation is required** — "Purge old" always opens the dialog (§3); it never deletes on the first tap.
- **Age label is display-only** — it derives from `trashedAt` at build time; no persisted string. Recompute on rebuild so a tile that ages past a bucket boundary updates on next paint.
- Keep `warning` (the amber token) out of all of these; the dialog's alert glyph uses `c.danger`, not `c.warning`.
