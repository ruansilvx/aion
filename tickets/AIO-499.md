# T12. **Completed via a native Windows desktop build, not Chrome**

— Claude in Chrome stayed unavailable after repeated retries, and
per `project.md` the sandboxed preview browser is known not to
render this app. Ran `flutter run -d windows` instead (a real,
already-supported target — `flutter devices` lists Windows
desktop) and drove the live `aion.exe` window via PowerShell/
Win32 API calls (`SetForegroundWindow`, `SetCursorPos` +
`mouse_event` for clicks/scroll, `SendKeys` for text/Enter/
Shift+Enter, `GetWindowRect` + `Graphics.CopyFromScreen` for
screenshots) — no desktop-automation tool was available, so this
was hand-rolled. Verified against a real chat ticket (AIO-4, a
live coding-execution chat) with real AI turns, not fixtures.
**Three real bugs found and fixed** (all invisible to `flutter
analyze`/`flutter test`, all now committed — see the app repo's
`78b62a9`):
1. `Positioned(top/left/right)` (no bottom) inside the collapsing
header's `Stack` left `OverflowBox` an unbounded height,
throwing "infinite size" / NaN render errors on every chat
ticket open. Fixed: `Positioned.fill`.
2. `shrinkOffset` isn't clamped to `[0, maxExtent - minExtent]`
for a pinned `SliverPersistentHeader` during fast/animated
scrolls (confirmed via console log:
`BoxConstraints(h=44.0)` given to `ChatMetaHeader`'s Column,
well below `minExtent=210`) — overflowed by ~50px. Fixed:
`currentHeight` explicitly clamped to `[minExtent, maxExtent]`.
3. `_StreamingBubbleState` declared
`SingleTickerProviderStateMixin` but creates two
`AnimationController`s (caret + border glow) — "multiple
tickers" exception on every in-flight AI reply. Fixed:
`TickerProviderStateMixin`.
Also bumped `_collapsedHeight` from the original 140 estimate to
210 (confirmed sufficient at both 1-line and 2-line-wrapped
titles, down to a 420px window width).
**Confirmed working**: scrolling down collapses
`TicketMetadataSection` smoothly into `ChatMetaHeader` (cross-
fade visibly correct mid-transition), scrolling back up
re-expands it, no overflow at any window width tested (420–1280
px) after the fixes; the compact header's back button navigates
correctly back to the tickets list; a real human message sent
via the compose field renders right-aligned immediately, and the
real AI reply renders left-aligned with full Markdown (headings,
bold, bullet lists, inline code, links, checkmark emoji) via
`MarkdownView`; compose field auto-expands across 3 lines with
the avatar/send button staying bottom-aligned; Shift+Enter
inserted a newline, plain Enter sent (and cleared/collapsed the
field); "MESSAGES · 2" eyebrow (not "COMMENTS") and "Message the
agent…" placeholder both confirmed; the non-chat `TASK` ticket
(AIO-1) confirmed fully unchanged — screen-level `AppHeader`,
full `TicketMetadataSection` including `_CodingExecutionSection`'s
error banner, plain "Add a comment…" pill compose row.
