# T3. Create `design_system/molecules/markdown_view.dart`:

`MarkdownView` — stateless, read-only widget parsing `source` via
`md.Document(extensionSet: md.ExtensionSet.gitHubWeb).parse(...)`
(`package:markdown`) and rendering the resulting AST via `AionText`/
`AionColors`/`AionRadius`/`AionSpacing` tokens per design.md's
per-tag mapping (headings 1-6, paragraphs with inline emphasis/links,
bullet/ordered/nested/task lists, fenced/indented code blocks,
blockquotes, horizontal rules, GFM tables via `Table`, not
`DataTable`). Images render alt text only. Any unrecognized node
falls back to a plain-text paragraph. No Material widgets. File
header + dartdoc on the class and constructor. Per design.md §2
MarkdownView (§2.1–§2.10, per-tag rendering rules).
