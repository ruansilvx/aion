# Update core/widgets — theme imports collapse to design_system.dart

For each file below, replace its `core/theme/*.dart` imports with a
single `import 'package:aion/core/design_system.dart';`. Any
`core/localization/context_localizations_x.dart` import stays as a
direct import (self-import exception: `core.dart` is `core`'s own
barrel, so files inside `core/` don't import it). Any import of another
`core/widgets/*.dart` sibling file stays direct.
