# Evaluator (`lib/core/automation/decision_graph_evaluator.dart`)

- [x] Add `'ruleBuilder': (input, params) => _evaluateRule(input, params)`
      to the existing `_conditionEvaluators` registry.
- [x] Add private `_fieldAccessors` map (`'attempt'` → `input.attempt`,
      `'sessionOverageDetected'` → `input.sessionOverageDetected`) and
      `_evaluateRule(DecisionEvalContext, Map<String, dynamic>)` —
      resolves `params['field']` via `_fieldAccessors`, parses
      `params['operator']` via `DecisionRuleOperator.values.byName`
      (guarded), compares to `params['value']` per operator. Returns
      `false` for any unrecognized field/operator or a `null` field
      value — never throws. Doc the new private members inline (not
      public API, but explain the defensive-`false` contract since it's
      load-bearing).
