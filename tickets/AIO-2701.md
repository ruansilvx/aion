# Bookkeeping repo strategy: dedicated repo vs. reuse source repo per project

Aion self-hosts itself, and its git-projected tickets/*.md + .aion/manifest.json are now tracked in the source repo (see chore/track-ticket-bookkeeping-in-source-repo, PR #102) rather than gitignored -- reusing the project's own source repo for bookkeeping so ticket data survives a machine switch.
