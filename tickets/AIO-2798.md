# Materialize baseline skill assets as .claude/skills/<name>/SKILL.md

New SkillMaterializationService resolves each skill asset's effective content (override-if-present, else bundled) and writes a real SKILL.md with synthesized YAML frontmatter, marked with an aion:managed-skill comment so a project's own hand-authored skills are never overwritten. Wired at project creation, baseline upgrade, and override save. Found and fixed a pre-existing bug in the same code path: CreateProjectCubit called baseline tailoring before the project actually existed in the repository, so architecture-conventions tailoring at project creation had been a silent no-op the whole time — existing tests mocked the service and never caught it.
