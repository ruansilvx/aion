# Spec Delta: Anthropic Messages API Provider

**Reconciled 2026-09-03:** cross-checked against the current `aion-arch/specs/providers.md` text — every distinctive symbol/behavior this delta names is still present and accurate (34/37 identifiers confirmed verbatim; the rest are prose/filename references, not drift). No content changes needed.

Delta against `aion-arch/specs/providers.md`. Read alongside
`proposal.md` and `design.md` in this change folder.

## ADDED

- **`ProviderId.anthropicMessagesApi`** (`core/contracts/provider_id.dart`)
  — second value on the previously one-value enum.
- **`AnthropicMessagesApiClient`** (`core/agent/anthropic_messages_api_client.dart`)
  — second `AgentModelClient` implementation. HTTP/SSE via `dio` against
  `https://api.anthropic.com/v1/messages`, unlike `ClaudeAgentSdkClient`'s
  subprocess/NDJSON transport. Returns `AgentErrorEvent` immediately (no
  network call) when no API key is configured or when
  `AgentRequest.toolsEnabled` is `true` (unsupported by this provider).
  A `429` response maps to `AgentOverageDetectedEvent` instead of
  `AgentErrorEvent` — a rate-limit is this provider's consumption
  signal.
- **`AnthropicMessagesApiProvider`** (`core/agent/anthropic_messages_api_provider.dart`)
  — second `AgentProvider` implementation. `displayName: 'Anthropic
  API'`; `supportedToolAccessTiers: {ToolAccessTier.noTools}` only (no
  `full` — this provider never gains coding-execution capability);
  `availableModels` — a fixed three-entry list mirroring
  `ClaudeAgentSdkProvider`'s Opus/Sonnet/Haiku labels, real Messages API
  model ids; `describeOverage` — the first real `CostConsumption`
  producer (`amountUsd: null`, the API's 429 body carries no dollar
  figure); `normalizeErrorMessage` — strips Anthropic-vendor-specific
  text the same way `ClaudeAgentSdkProvider.normalizeErrorMessage`
  strips Claude Code CLI text.
- **`AnthropicApiKeyRepository`** (`features/providers/domain/repositories/anthropic_api_key_repository.dart`,
  abstract) / **`SecureStorageAnthropicApiKeyRepository`**
  (`features/providers/data/repositories/`) — `getApiKey()`/
  `setApiKey(String?)`, backed by `flutter_secure_storage` (one key,
  `provider_config.anthropic_api_key`). First real secret Aion stores;
  `flutter_secure_storage` was previously an unused dependency.
- **`AnthropicProviderConfigCubit`** / **`AnthropicProviderConfigState`**
  (`features/providers/presentation/cubit/`) — loads whether a key is
  stored (never auto-tests — a Messages API ping is a real billed call,
  unlike Agent SDK's flat-plan ping), saves a new/cleared key, and runs
  an explicit, user-triggered connection test against this provider's
  cheapest model.
- **Settings screen "PROVIDERS" section** — a new `_AnthropicApiKeySection`
  (obscured API-key field with a reveal toggle, Save button, connection
  badge, provider-scoped Test Connection button), placed between the
  existing provider status card and the "MODELS" eyebrow.
- **`AppDropdown<T>.itemRowLabel`** (`design_system/molecules/app_dropdown.dart`,
  new optional param, `null` default) — a separate label function for
  the open item panel, distinct from the closed trigger's `itemLabel`.
  Used by the MODELS tier dropdowns to show a muted provider-name prefix
  once a phase's model list spans more than one provider — the exact
  scenario `changes/archive/pluggable-provider-abstraction/design.md`
  §6 pre-specified as "FUTURE ONLY," now realized.
- **`AppTextField.obscureText`/`.suffixIcon`** (`design_system/atoms/app_text_field.dart`,
  new optional params, `false`/`null` default) — masked-input support,
  first used by the API-key field.

## MODIFIED

- **`ProviderRegistry`/`StaticProviderRegistry`** — now constructed
  with two entries (`ClaudeAgentSdkProvider`, `AnthropicMessagesApiProvider`)
  instead of one. No interface change — `providerById`/`availableProviders`
  behave exactly as documented, now with a real second list entry to
  exercise them against.
- **`ModelPhase.requiredToolAccessTier`'s filter (`ModelRoutingCubit.load`)**
  — previously real but a no-op with only one registered provider. Now
  has a visible effect: Frontier/Capable tier dropdowns (require
  `noTools`) offer both providers' models; the Execution tier (requires
  `full`) still offers only `ClaudeAgentSdkProvider`'s.
- **`ProviderSettingsCubit`/`ProviderSettingsReady`** — gains
  `providerDisplayName` (computed from the resolved `AgentProvider` at
  emit time). `_ProviderStatusCard`'s title/subline switch from
  hardcoded "Claude Agent SDK"/"Authenticated via your Claude plan"
  literals to provider-derived text — the connection test itself is
  unchanged (still always pings whichever provider `ModelPhase.frontier`
  currently resolves to).
- **`pubspec.yaml`** — adds `dio` as a new dependency, the package
  `project.md` §5 already names for this transport.
- **`features/providers/providers.dart`** barrel — exports the new
  repository interface and cubit/state; the secure-storage data-layer
  implementation stays unexported, matching
  `SharedPrefsModelRoutingRepository`'s existing precedent.

## REMOVED

None.
