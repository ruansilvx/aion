# **T08** — Create `lib/features/tickets/presentation/screens/tickets_board_view.dart`

File header comment per convention. Implement in this file, in order:
1. **`ticketStatusLabel(TicketStatus status)`** — top-level function,
extracted from `StatusIndicator`'s current private `_statusLabel`
switch in `tickets_list_screen.dart` (see T09 — remove it there,
define it here, import it back). Dartdoc it.
2. **`TicketBoardView`** — `StatelessWidget`, prop `List<Ticket> tickets`
(caller-filtered). Groups by `status`, renders
`SingleChildScrollView(scrollDirection: Axis.horizontal)` → `Row` of
`BoardColumn`, one per `TicketStatus.values` in declared order (all 6
always render). Column width fixed (e.g. `280`), `AionSpacing.sp12`
gaps, `AionSpacing.sp20` outer padding. All colors/spacing/radii via
`ThemeScope`/`AionSpacing`/`AionRadius` — no raw literals. Dartdoc the
class per the project's class-doc convention.
3. **`BoardColumn`** — `StatelessWidget`, props `TicketStatus status`,
`List<Ticket> tickets`. Header: `ticketStatusLabel(status)` +
count badge. Body: `DragTarget<Ticket>` (`onWillAcceptWithDetails`
always `true`; `onAcceptWithDetails` calls
`context.read<TicketsCubit>().updateTicketStatus(details.data.id, status)`
only when `details.data.status != status`) wrapping a vertical
`ListView.separated` of `TicketBoardCard`. Tint background
`c.primarySubtle` while `candidateData.isNotEmpty`. Dartdoc the class.
4. **`TicketBoardCard`** — `StatelessWidget`, prop `Ticket ticket`.
Card visual per `design.md` (`DecoratedBox` + `AionShadows.card`,
reusing `TypeChip`/`PriorityBadge` from `tickets_list_screen.dart` —
import them). Wrapped in `GestureDetector(onTap: () =>
context.go('/tickets/${ticket.id}'))`,
`Semantics(label: '${ticket.ticketId} ${ticket.title}, status:
${ticketStatusLabel(ticket.status)}', button: true)`, and
`FocusableActionDetector` + `ActivateIntent` (same activate-on-Enter
pattern as `TicketListTile`). Drag wrapper branches on `isMobile`
from `core/utils/platform_utils.dart`:
`LongPressDraggable<Ticket>` on mobile, `Draggable<Ticket>`
otherwise — both with `data: ticket`, a `feedback` builder (card at
`Opacity(0.9)` + `AionShadows.fab`) and `childWhenDragging` (card at
`Opacity(0.35)`). Includes a trailing `MoveToStatusMenu(ticket: ticket)`.
Dartdoc the class, including the drag-vs-tap gesture-arena note from
`design.md`.
5. **`MoveToStatusMenu`** — `StatefulWidget`, prop `Ticket ticket`.
Icon-button trigger (`PhosphorIcons.dotsThreeLight`),
`Semantics(button: true, label: 'Move ${ticket.ticketId} to another
status')`. On tap, opens an `OverlayEntry` via `Overlay.of(context)`
using the same `LayerLink`/`CompositedTransformFollower`/
outside-tap-dismiss pattern as `AppDropdown`
(`core/widgets/app_dropdown.dart`) — including the `mounted` guard
before `setState` in the dismiss callback (see `project.md`
Testing note on the `AppDropdown` overlay-dismiss crash). Lists
`TicketStatus.values.where((s) => s != ticket.status)`; selecting one
calls `context.read<TicketsCubit>().updateTicketStatus(ticket.id,
selected)` and closes the overlay. Dartdoc the class and its dispose
behavior (remove any open `OverlayEntry`).
