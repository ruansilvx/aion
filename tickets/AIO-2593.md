# 2. Data Layer — Drift Schema

- [x] **T05** — Create `lib/features/tickets/data/models/ticket_model.dart`
  Define two Drift table classes:
  1. `TicketsTable` — all columns from design.md including: `ticket_id`
     (TextColumn NOT NULL UNIQUE), `priority` (TextColumn NOT NULL,
     `withDefault(const Constant('none'))`), `estimate` (IntColumn nullable),
     `time_spent` (IntColumn nullable).
  2. `TicketIdSequenceTable` — `id` (IntColumn, PRIMARY KEY) and
     `seq` (IntColumn, NOT NULL, default 0).
  Use `TextColumn`, `BlobColumn`, `IntColumn`. No FK constraints.

- [x] **T05b** — Create `lib/features/tickets/data/models/ticket_link_model.dart`
  Define `TicketLinksTable` Drift table: `id` (TextColumn PK), `source_ticket_id`
  (TextColumn NOT NULL), `target_ticket_id` (TextColumn NOT NULL),
  `link_type` (TextColumn NOT NULL). No FK constraints.

- [x] **T05c** — Create `lib/features/tickets/data/models/ticket_comment_model.dart`
  Define `TicketCommentsTable` Drift table: `id` (TextColumn PK), `ticket_id`
  (TextColumn NOT NULL), `content` (TextColumn NOT NULL), `author_type`
  (TextColumn NOT NULL), `ai_model` (TextColumn nullable),
  `created_at` (IntColumn NOT NULL). No `updated_at` column. No FK constraints.

- [x] **T06** — Create `lib/features/tickets/data/daos/ticket_dao.dart`
  Define `TicketDao` with
  `@DriftAccessor(tables: [TicketsTable, TicketIdSequenceTable])`.
  Methods:
  - `getAllTickets()` — ordered by `created_at` DESC.
  - `getTicketById(String id)`.
  - `insertTicket(TicketsTableCompanion entry, String prefix)` — runs in a
    Drift transaction: read `seq` → increment → update row → build
    `ticketId` as `'$prefix-$newSeq'` → insert ticket (including `priority`
    column). Returns the generated `ticketId` string.

- [x] **T06b** — Create `lib/features/tickets/data/daos/ticket_link_dao.dart`
  Define `TicketLinkDao` with `@DriftAccessor(tables: [TicketLinksTable])`.
  Methods: `getLinksForTicket(String ticketId)` (WHERE source OR target = id),
  `insertLink(TicketLinksTableCompanion entry)`.

- [x] **T06c** — Create `lib/features/tickets/data/daos/comment_dao.dart`
  Define `CommentDao` with `@DriftAccessor(tables: [TicketCommentsTable])`.
  Methods: `getCommentsForTicket(String ticketId)` (ordered by `created_at`
  ASC), `insertComment(TicketCommentsTableCompanion entry)`.
  No UPDATE or DELETE methods exposed — append-only by construction.

- [x] **T07** — Create `lib/core/database/app_database.dart`
  Define `AppDatabase` with:
  ```dart
  @DriftDatabase(
    tables: [TicketsTable, TicketIdSequenceTable, TicketLinksTable, TicketCommentsTable],
    daos: [TicketDao, TicketLinkDao, CommentDao],
  )
  ```
  Implement platform-conditional `_openConnection()`:
  - Native: `driftDatabase(name: 'aion')` from `drift_flutter`.
  - Web: `WasmDatabase.open(...)` from `drift/wasm`.
  Schema version: 1. `MigrationStrategy.onCreate`: seed
  `TicketIdSequenceTable` with `(id: 1, seq: 0)`. All four tables created
  in `onCreate`.

- [x] **T08** — Run codegen:
  ```
  flutter pub run build_runner build --delete-conflicting-outputs
  ```
  Verify `app_database.g.dart` and `ticket_dao.g.dart` are generated.
