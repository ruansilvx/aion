# Create `lib/features/projects/presentation/screens/

override_editor_screen.dart` — `OverrideEditorScreen`, using
`AppTextField(maxLines: null)` for the editor rather than a
bespoke `_OverrideTextEditor` (Aion's own established "one
Material `TextField`, always wrapped" precedent — see
`AppTextField`'s own dartdoc — so no new primitive was needed).
Status-line variant A uses the new `aiBubbleBorder(isDark)` token;
variant B reuses the existing `noticeFill`/`noticeBorder` helpers.
Save button label switches between "Save override"/"Create
override" per `isOverridden`, disabled while pristine or saving.
Reset-to-default and discard-with-unsaved-changes are out of
scope per proposal.md.
