# `lib/features/tickets/data/services/ticket_parent_trash_service.dart`:

removed the `_triggerGitProjection` private method and its two
call sites inside `trash()`/`restore()`. **Correction**: the
`_gitProjector`/`_projectRootPath` *fields* turned out to be
dead once `_triggerGitProjection` was gone (nothing else read
them — `_rollupRecomputer` is built from the raw constructor
*parameters*, not these fields), so they were removed too; the
constructor's `gitProjector`/`projectRootPath` *parameters*
stayed, exactly as planned. Updated `trash()`/`restore()`'s
dartdoc, plus the class-level dartdoc, to reflect that
single-ticket projection now happens inside `_repository` itself.
