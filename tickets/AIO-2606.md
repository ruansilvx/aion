# 4. Core — Design Tokens, Theme, Utils, Router

- [x] **T10a** — Create `lib/core/theme/aion_colors.dart`

  design.md §1.1 and §1.2. Key rules:
  - Both are `@immutable` classes with `const` constructors — **no static
    constants** on the classes themselves; instances are the API.
  - Declare the four instances at the top of the file as top-level `const`
    values: `arcticPriority`, `obsidianPriority`, `arctic`, `obsidian`.
    Order: priority instances first (referenced by color instances).
  - `AionColors` fields: `background`, `surface`, `surfaceHover`, `primary`,
    `primaryHover`, `primarySubtle`, `secondary`, `success`, `danger`,
    `warning`, `textPrimary`, `textSecondary`, `textMuted`, `border`,
    `borderStrong`, `priority` (AionPriorityColors), `typeTask`, `typeStory`,
    `typeEpic`.
  - `AionPriorityColors` fields: `criticalBg`, `criticalFg`, `highBg`,
    `highFg`, `mediumBg`, `mediumFg`, `lowBg`, `lowFg`.
  - Arctic hex values (all `Color(0xFF...)` constants):
    background `0xFFEDF2F8`, surface `0xFFFBFCFE`, surfaceHover `0xFFE4EDF6`,
    primary `0xFF2E86D4`, primaryHover `0xFF1E6DB6`, primarySubtle `0xFFDBE9F7`,

- [x] **T10b** — Create `lib/core/theme/aion_text.dart`

  TextStyle` fields exactly as specified in design.md §1.5. Rules:
  - Private font-family constants at top: `_ui = 'Manrope'`,
    `_mono = 'JetBrainsMono'`. All styles reference these constants only.
  - All `letterSpacing` values are in logical pixels as listed (already
    converted from em — do not reconvert).
  - Styles to define (exact values):
    - `display`: fontFamily `_ui`, size 32, w800, letterSpacing -0.64, height 1.1
    - `h1`:      fontFamily `_ui`, size 25, w800, letterSpacing -0.50, height 1.15
    - `h2`:      fontFamily `_ui`, size 22, w800, letterSpacing -0.22, height 1.25
    - `body`:    fontFamily `_ui`, size 15, w500, height 1.5
    - `bodySm`:  fontFamily `_ui`, size 13.5, w400, height 1.6
    - `cardTitle`: fontFamily `_ui`, size 14, w600, height 1.45
    - `label`:   fontFamily `_ui`, size 12, w700 (form field labels)
    - `button`:  fontFamily `_ui`, size 14, w700
    - `chip`:    fontFamily `_ui`, size 10.5, w700, letterSpacing 0.53
    - `priorityBig`: fontFamily `_ui`, size 10.5, w800, letterSpacing 0.53

- [x] **T10d** — Create `lib/core/theme/aion_shadows.dart`
  Implement `AionShadows` as an `abstract final class` with static
  `List<BoxShadow>` methods (not constants — shadow colors depend on the
  active theme's `AionColors`) matching the four elevation levels in §1.8:
  - `card(AionColors c)` → subtle card shadow for Arctic floating cards:
    `[BoxShadow(color: c.textPrimary.withOpacity(0.07), blurRadius: 2,
    spreadRadius: 0, offset: Offset(0, 1))]`. Returns empty list for
    Obsidian (no shadow; border separation is used instead).
  - `fab(AionColors c)` → FAB / send button shadow:
    `[BoxShadow(color: c.primary.withOpacity(isDark ? 0.60 : 0.45),
    blurRadius: 28, spreadRadius: -8, offset: Offset(0, 14))]`.
    Accept `bool isDark` as second parameter.
  - `focus(AionColors c)` → focus ring (solid 3px spread, no blur):
    `[BoxShadow(color: c.primary.withOpacity(isDark ? 0.30 : 0.16),
    blurRadius: 0, spreadRadius: 3)]`.
  - `aiGlow(AionColors c)` → AI mark glow:
    `[BoxShadow(color: c.primary.withOpacity(isDark ? 0.60 : 0.45),
    blurRadius: 14)]`.
  No Material import. Accept `bool isDark` only on shadows that need it.

- [x] **T10f** — Create `lib/core/theme/aion_theme.dart`
  Implement `AionThemeData` as an `@immutable` plain Dart class. Rules:
  - Fields: `colors` (`AionColors`), `isDark` (`bool`).
  - Constructor: `const AionThemeData({required this.colors, required this.isDark})`.
  - Two **top-level** `const` instances (NOT static members on the class):
    ```dart
    const aionThemeArctic   = AionThemeData(colors: arctic,   isDark: false);
    const aionThemeObsidian = AionThemeData(colors: obsidian, isDark: true);
    ```
  - Helper getter on `AionThemeData`:
    ```dart
    double get fillAlpha => isDark ? fillAlphaObsidian : fillAlphaArctic;
    ```
  - Widgets read color as `t.colors.primary`; typography via `AionText` statics
    with `.copyWith(color: t.colors.textPrimary)` at every call site. `AionText`
    is NOT a field on `AionThemeData` — it is globally accessible.
  - **No `ThemeData`, no `ThemeExtension`, no Material import.**
  - File imports: `aion_colors.dart` (for `AionColors`, `arctic`, `obsidian`)
    and `aion_radius.dart` (for `fillAlphaArctic`, `fillAlphaObsidian` — these
    live in `aion_colors.dart` per T10a).

- [x] **T10g** — Create `lib/core/theme/theme_scope.dart`
  `ThemeScope extends InheritedWidget`. Rules:
  - Field: `final AionThemeData theme`.
  - Static accessor:
    ```dart
    static AionThemeData of(BuildContext context) {
      final scope = context.dependOnInheritedWidgetOfExactType<ThemeScope>();
      assert(scope != null, 'ThemeScope not found in widget tree');
      return scope!.theme;
    }
    ```
  - `updateShouldNotify(ThemeScope old)` → `theme != old.theme`.
  - **No Material import.** `AionThemeData` is the sole type this widget
    exposes. `ThemeScope` wraps the root `WidgetsApp.router` (set in T18).
  - Usage pattern in ALL widget `build` methods:
    ```dart
    final t = ThemeScope.of(context);
    // t.colors.primary
    // t.colors.textPrimary
    // t.isDark
    // t.fillAlpha
    // AionText.body.copyWith(color: t.colors.textPrimary)
    ```
  - `AionText`, `AionRadius`, `AionSpacing`, `AionShadows` are accessed as
    pure statics — never through `ThemeScope`.
