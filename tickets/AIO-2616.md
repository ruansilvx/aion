# 4b. Core — Primitive Widget Components

These in-house components replace Material widgets. Build them before screens.

- [x] **T10h** — Create `lib/core/widgets/app_button.dart`
  `AppButton` stateless widget. Exactly per design.md §2.1. Rules:
  - No `ElevatedButton`, `TextButton`, or any Material widget. Use:
    `GestureDetector` → `FocusableActionDetector` → `MouseRegion` →
    `AnimatedScale` (press: 0.98) → `DecoratedBox` → `Padding` → `Row`
    (optional leading icon + `Text`).
  - Variants via a `AppButtonVariant` enum:
    `primary`, `secondary`, `ghost`, `destructive`.
  - Shared props: `onPressed` (VoidCallback?), `label` (String),
    `icon` (PhosphorIconData?), `isFullWidth` (bool, default false).
  - Per-variant styling (all from `ThemeScope` + token statics only — no raw
    values):

    | Variant      | fill               | text color      | border                     | padding (V×H)  | shadow              |
    |---|---|---|---|---|---|
    | primary      | `c.primary`        | `Color(0xFFFFFFFF)` | none               | `10 × 17`      | FAB glow (blur 18, spread −9, `fabGlow`) |
    | secondary    | `c.surfaceHover`   | `c.textPrimary` | 1px `c.borderStrong`       | `9 × 16`       | none                |
    | ghost        | transparent        | `c.primary`     | none                       | `10 × 8`       | none                |
    | destructive  | `c.danger`         | `Color(0xFFFFFFFF)` | none               | `10 × 17`      | none                |

  - Hover state: primary → `c.primaryHover`; secondary fill → `c.border`.
    Use `ValueNotifier<bool>` + `ValueListenableBuilder` for hover tracking
    (never `setState` — widget is stateless; use `StatefulWidget` only if
    hover/focus state requires it, which it does — make it `StatefulWidget`).
  - Disabled (`onPressed == null`): opacity 0.45, no shadow, scale locked 1.0.
  - Full-width submit variant (`isFullWidth: true`): padding `15` all around,
    `BorderRadius.circular(13)`, text `AionText.button.copyWith(fontSize: 15)`,
    width fills parent via `SizedBox.expand`.
  - Text: `AionText.button` (14px w700). Leading icon `PhosphorIcon` at 18px.
    Gap between icon and label: `AionSpacing.sp8`.
  - Radius: `BorderRadius.all(AionRadius.md)` (except full-width: radius 13 as
    above).
  - `Semantics(button: true, label: label)` wrapping the entire widget.
  - No raw `Color(0x...)` literals except the two `#FFFFFF` text colors for
    primary/destructive (white on color background — token doesn't carry white).
    Annotate with `// white text on colored fill — no token for white` inline.

- [x] **T10i** — Create `lib/core/widgets/app_text_field.dart`
  `AppTextField` stateful widget. Exactly per design.md §2.5. Rules:
  - Use Flutter's `TextField` but supply ALL decoration values explicitly —
    no `Theme` defaults may be relied upon. This is the sole permitted
    Material widget in the widget layer (see Material Coupling Audit in
    design.md). Any `ThemeData`-driven default that leaks must be overridden.
  - Props: `controller` (TextEditingController), `focusNode` (FocusNode?),
    `labelText` (String?), `hintText` (String?), `maxLines` (int, default 1),
    `textInputAction` (TextInputAction?), `onSubmitted` (ValueChanged<String>?),
    `isRequired` (bool, default false), `isOptional` (bool, default false).
  - Layout: `Column(crossAxisAlignment: start)` with:
    1. If `labelText` != null: `Padding(bottom: AionSpacing.sp4)` →
       `Row` with `Text(labelText, style: AionText.label.copyWith(color: t.colors.textSecondary))`
       + if `isRequired`: `Text(' *', style: AionText.label.copyWith(color: t.colors.danger))`
       + if `isOptional`: `Text('  Optional', style: AionText.bodySm.copyWith(color: t.colors.textMuted, fontWeight: FontWeight.w500))`.
    2. `TextField` with explicit `InputDecoration`:
       - `fillColor: t.colors.surface`, `filled: true`
       - `contentPadding: EdgeInsets.symmetric(horizontal: 14, vertical: 12)`
       - `border`, `enabledBorder`: `OutlineInputBorder(borderRadius: BorderRadius.all(AionRadius.lg), borderSide: BorderSide(color: t.colors.border, width: 1))`
       - `focusedBorder`: `OutlineInputBorder(borderRadius: BorderRadius.all(AionRadius.lg), borderSide: BorderSide(color: t.colors.primary, width: 1.5))`
       - `hintStyle: AionText.bodySm.copyWith(color: t.colors.textMuted)` (or `AionText.body` for multiline)
       - `hintText`: the passed `hintText`
       - Set `isDense: true`, `isCollapsed: false`.
       - No `labelText` inside `InputDecoration` (label rendered above separately).
  - Focus ring: when focused, wrap `TextField` in a `DecoratedBox` adding
    `AionShadows.focus(t.colors, t.isDark)` as `boxShadow` on the
    `BorderRadius.all(AionRadius.lg)` container.
    Use `focusNode` listener + `setState` to toggle focus ring.
  - Multiline (`maxLines > 1`): `minLines: 5`, `textAlignVertical: TextAlignVertical.top`,
    text style `AionText.body.copyWith(color: t.colors.textPrimary)`.
  - Single-line: text style `AionText.bodySm.copyWith(color: t.colors.textPrimary, fontSize: 14)`.
  - No raw colors or sizes. All spacing via `AionSpacing.*`, radii via `AionRadius.*`.

- [x] **T10j** — Create `lib/core/widgets/app_dropdown.dart`
  `AppDropdown<T>` generic stateful widget. Exactly per design.md §2.5
  dropdown variant. No `DropdownButton` or any Material overlay widget.
  - Props: `value` (T), `items` (List<T>), `onChanged` (ValueChanged<T>),
    `labelText` (String?), `itemLabel` (String Function(T)) — converts enum
    to display string, `isRequired` (bool, default false).
  - Trigger (closed state):
    - `CompositedTransformTarget` wrapping a `GestureDetector` + `FocusableActionDetector`.
    - Visual: `DecoratedBox` matching `AppTextField` closed state exactly:
      fill `t.colors.surface`, radius `BorderRadius.all(AionRadius.lg)`,
      border 1px `t.colors.border`.
    - Padding: `EdgeInsets.symmetric(horizontal: 14, vertical: 12)`.
    - Content: `Row` — `Expanded(Text(itemLabel(value), style: ...textPrimary))`
      + `PhosphorIcon(PhosphorIcons.caretDown, size: 12, color: t.colors.textMuted)`.
    - Same label rendering above as `AppTextField` (same column structure).
  - Open state: inserts `OverlayEntry` via `Overlay.of(context)`.
    - `CompositedTransformFollower` linked to the trigger's `LayerLink`.
    - Overlay `DecoratedBox`: fill `t.colors.surface`, radius `AionRadius.lg`,
      border 1px `t.colors.borderStrong`, shadow `AionShadows.card(t.colors)`.
    - Items: `Column` of `GestureDetector` rows — padding `12×14`, on tap:
      select value + close overlay. Selected item: text `t.colors.primary`,
      background `t.colors.primarySubtle`. Others: text `t.colors.textPrimary`.
    - Dismiss on outside tap: `TapRegion` or a barrier `GestureDetector`
      placed beneath the overlay (full-screen transparent, removes overlay).
  - Focused state border: 1.5px `t.colors.primary` (same as `AppTextField`).
  - `Semantics(button: true, label: '${labelText ?? ''} ${itemLabel(value)}')`.
  - All sizing from `AionSpacing.*` and `AionRadius.*`. No raw literals.

- [x] **T10k** — Create `lib/core/widgets/app_spinner.dart`
  `AppSpinner` stateful widget (needs `SingleTickerProviderStateMixin` for
  the animation controller). Rules:
  - No `CircularProgressIndicator`. Render a sweeping arc via
    `AnimatedBuilder` + `CustomPaint`.
  - `CustomPainter` draws a `Paint` arc:
    - Stroke width: 2.5px.
    - Color: `t.colors.primary` (from `ThemeScope.of(context)` passed in, or
      read inside `build`).
    - Arc sweep: 270° starting from top; rotated by animation value × 2π.
  - `AnimationController(vsync: this, duration: Duration(milliseconds: 900))`
    repeating.
  - Default `size`: `20.0`. Expose `size` (double) prop for call-site control.
  - `Semantics(label: 'Loading')` wrapping the widget.
  - No Material import. No raw colors — only `t.colors.primary`.

- [x] **T10l** — Create `lib/core/widgets/app_toast.dart`
  `AppToast` — static `show(BuildContext context, String message)` method.
  Rules:
  - No `SnackBar`, no `ScaffoldMessenger`. Uses `Overlay.of(context)`.
  - Inserts an `OverlayEntry` at the bottom of the screen:
    - `Positioned(bottom: AionSpacing.sp24, left: AionSpacing.sp20, right: AionSpacing.sp20)`.
    - Visual: `DecoratedBox` — fill `t.colors.surface`, border 1px
      `t.colors.borderStrong`, radius `BorderRadius.all(AionRadius.md)`,
      shadow `AionShadows.card(t.colors)`.
    - Padding: `EdgeInsets.symmetric(horizontal: AionSpacing.sp16, vertical: AionSpacing.sp12)`.
    - Text: `AionText.bodySm.copyWith(color: t.colors.textPrimary)`.
  - Read theme at insertion time: `ThemeScope.of(context)`.
  - Auto-dismisses after `Duration(seconds: 3)` via `Future.delayed`.
  - `Semantics(liveRegion: true, label: message)` on the toast container.
  - No `Scaffold`, no Material import.

- [x] **T10m** — Create `lib/core/widgets/app_header.dart`
  `AppHeader` stateless widget. Exactly per design.md §3.1 and §3.2.
  No `AppBar`, no Material widget.
  - Props: `title` (String), `showBack` (bool, default false),
    `onBack` (VoidCallback?), `trailing` (Widget?).
  - Root: `ColoredBox(color: t.colors.surface)` wrapping a `Padding`.
    - Padding from prop `EdgeInsets padding` (default
      `EdgeInsets.fromLTRB(20, 6, 20, 14)` — list header style;
      callers pass `fromLTRB(20, 6, 20, 16)` for create, `fromLTRB(20, 6, 20, 12)`
      for detail). Expose `padding` as a named prop.
  - Content: `Row(children: [backButton?, Expanded(titleWidget), trailing?])`.
  - Back button (when `showBack: true`):
    - `GestureDetector(onTap: onBack)` wrapping a `Semantics(label: 'Back')`.
    - Visual: `DecoratedBox` — fill `t.colors.surfaceHover`, border 1px
      `t.colors.border`, `BorderRadius.all(AionRadius.iconBtn)` (radius 11).
    - Size: `37×37` via `SizedBox`.
    - Icon: `PhosphorIcon(PhosphorIcons.caretLeft, size: 18, color: t.colors.textSecondary)`.
    - `Padding(right: AionSpacing.sp12)` between back button and title.
  - Title: `Text(title, style: AionText.h2.copyWith(color: t.colors.textPrimary))`.
    For the list screen eyebrow, callers compose their own header layout
    (eyebrow + h1); `AppHeader` covers the back-button + h2 pattern used by
    create and detail screens.
  - Trailing: rendered as-is at right side, e.g. an outlined avatar widget or
    a `PhosphorIcon` more-menu button.
  - No `AppBar`, no `Scaffold`, no `Theme`, no Material import.
