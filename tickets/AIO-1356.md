# T5. Create `design_system/molecules/markdown_editor.dart`:

`MarkdownEditor` — stateful, responsive editor per design.md:
`LayoutBuilder` with `isNarrow = constraints.maxWidth <= 640`; narrow
layout is a view/edit toggle (view renders `MarkdownView`, edit
renders an `AppTextField` with `maxLines: null` plus an explicit
Save/Cancel row); wide layout is a live split view (`AppTextField`
left, `AionColors.border` divider, `MarkdownView` right, both
independently scrollable) with the same Save/Cancel row beneath.
Commits only via explicit Save, calling the caller-supplied
`onCommit` with the trimmed text — never calls a repository or Cubit
method directly. File header + dartdoc on the class, constructor,
and all public fields. Per design.md §1 MarkdownEditor (§1.1–§1.7:
narrow toggle, wide split view, saving/error/empty states).
