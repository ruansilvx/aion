# **T06** — Create `lib/features/tickets/data/daos/ticket_dao.dart`

Define `TicketDao` with
`@DriftAccessor(tables: [TicketsTable, TicketIdSequenceTable])`.
Methods:
- `getAllTickets()` — ordered by `created_at` DESC.
- `getTicketById(String id)`.
- `insertTicket(TicketsTableCompanion entry, String prefix)` — runs in a
Drift transaction: read `seq` → increment → update row → build
`ticketId` as `'$prefix-$newSeq'` → insert ticket (including `priority`
column). Returns the generated `ticketId` string.
