# **T09** — Modify `lib/features/tickets/presentation/screens/tickets_list_screen.dart`

- Remove `StatusIndicator`'s private `_statusLabel` method; import and
call `ticketStatusLabel` from `tickets_board_view.dart` instead.
- Add private `enum _TicketViewMode { list, board }` and
`_TicketViewMode _viewMode = _TicketViewMode.list` state field on
`_TicketsListScreenState`.
- Add a two-icon view-mode toggle to the header `Row`, positioned left
of the existing avatar `DecoratedBox` (list icon, board icon —
`PhosphorIcons.hexagonLight` for board per the design-system icon
table; confirm exact `phosphoricons_flutter` identifiers for both
exist, adjust names if the package differs). Active icon: `c.primary`
on `c.primarySubtle`; inactive: `c.textMuted`, transparent. Each
wrapped in `Semantics(button: true, label: 'Switch to list view'` /

via `setState`.

`TicketStatusUpdating(:final tickets) || TicketStatusUpdated(:final tickets)`
as an additional case matching the existing `TicketCreating`/
`TicketCreated` case's rendering (List mode: same
`ListView.separated`).
- Inside the switch's list-bearing branches, when `_viewMode ==
_TicketViewMode.board`: filter `tickets` to
`{TicketType.task, TicketType.story}` and render
`TicketBoardView(tickets: filtered)` instead of `ListView.separated`.
Empty-state text ("No tickets yet") still applies pre-filter (i.e. if
the *unfiltered* list is empty); if the filtered board list is empty
but the unfiltered list isn't, `TicketBoardView` renders its 6 empty
columns rather than a separate empty-state message.
- Import `tickets_board_view.dart`.
