    - `RepositoryProvider<TicketRepository>` → `DriftTicketRepository`
    - `RepositoryProvider<CommentRepository>` → `DriftCommentRepository`
    - `RepositoryProvider<TicketLinkRepository>` → `DriftTicketLinkRepository`

    screen-scoped in T17).
  - Wrap in `ThemeScope` (initial brightness from
    `WidgetsBinding.instance.platformDispatcher.platformBrightness`).

    `routerConfig: appRouter`, `color: aionThemeArctic.colors.primary`.
    (`WidgetsApp` requires a `color` param for the system UI overlay — use the
    arctic primary as a stable fallback; it does not drive any widget styling.)
  - No `MaterialApp`, no `ThemeData`, no `ThemeMode` anywhere in this file.
