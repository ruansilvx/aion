# Spec Delta: Editable Ticket Parent (`parentId`)

**Reconciled 2026-09-03:** checked against the current `aion-arch/specs/tickets.md's Screens section (ticket detail's TicketParentPicker)` — the mechanism/behavior this delta describes is still present and architecturally coherent with current text. Identifiers the automated screen flagged as missing are private-method requalification, line-wrapped tokens, or names covered in a neighboring section rather than repeated here — not behavioral drift. TicketsCubit.updateTicketParent is confirmed still the live write path; Ticket Parent Selection UX (a later ticket) built its picker-overlay polish on top of this foundation additively, not as a replacement.

## ADDED

- **`TicketRepository.updateTicketParent(String id, String? parentId)`** —
  updates only `parentId` and `updatedAt` for the ticket with internal id
  `id`. Pass `null` to clear the parent. Performs no validation of its
  own (no self-reference or cycle check) — callers must validate first.
  Throws if `id` does not exist. Implemented by `DriftTicketRepository`
  via `TicketDao.updateFields` (no schema change — `parent_id` is
  already a nullable column).

- **`TicketsCubit.getValidParentCandidates(Ticket ticket)`** — returns
  every ticket except `ticket` itself and any of its structural
  descendants (transitively, via `parentId`). Does not emit a state;
  used to populate the parent-picker overlay's candidate list.

- **`TicketsCubit.updateTicketParent(Ticket ticket, String? newParentId)`**
  — the sole write path for reparenting. Rejects `newParentId ==
  ticket.id` (self-parent) and any `newParentId` that is a descendant of
  `ticket` (would create a cycle) by emitting
  `TicketsError(reason: TicketsErrorReason.invalidParent)` followed by a
  re-emitted `TicketDetailLoaded` for the unchanged ticket — the
  reparent is rejected, not "confirmed but failed." On a valid
  `newParentId` (including `null`, to clear the parent), persists via
  `TicketRepository.updateTicketParent` and emits the refreshed
  `TicketDetailLoaded`.

- **`TicketsErrorReason.invalidParent`** — new enum value; classifies
  the error above for `ticketsErrorMessage` and the detail screen's
  toast listener.

- **`TicketParentPicker` widget** (`ticket_detail_screen.dart`) — an
  overlay-picker on the ticket detail screen showing the current parent
  (or a "+ PARENT" placeholder), with a search field and scrollable
  candidate list (from `getValidParentCandidates`) plus a "No parent"
  option to clear. Selecting a candidate calls
  `TicketsCubit.updateTicketParent`.

- l10n keys: `ticketDetailAddParent`, `ticketDetailChangeParent`,
  `ticketDetailParentLabel`, `ticketDetailNoParentOption`,
  `ticketDetailParentSearchHint`, `ticketInvalidParentError`.
