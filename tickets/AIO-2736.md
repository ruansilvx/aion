# `lib/core/routing/app_router.dart`: move the `RepositoryProvider`

entries for `GitRepositoryClient` and `TicketMarkdownSerializer`
(and `TicketGitProjector`, which depends on both) from their
current position inside the later `if (rootPath != null) [...]`
block to a new `if (rootPath != null) [...]` block placed
*before* `RepositoryProvider<TicketRepository>` in the provider
list — leave `ActiveTicketViewRegistry`, `TicketParentTrashService`,
`TicketMarkdownReconciler`, `TicketRepairService` in their
current position (they still need `TicketRepository` to already
exist above them). Change `RepositoryProvider<TicketRepository>`'s
`create` callback from `(_) => DriftTicketRepository(_database)`
to construct a plain `DriftTicketRepository`, then — when
`rootPath != null` — wrap it in
`GitProjectingTicketRepository(drift, context.read<TicketGitProjector>(), rootPath)`
and return that instead. Update the comment block currently
documenting the "Desktop-only project-scoped services" `if`
block to reflect the split (which providers moved earlier and
why).
