# Widget layer — manual linking (design-gated)

- [x] T13. `features/tickets/presentation/widgets/ticket_link_picker.dart`
      — `TicketLinkPicker` gains a required `linkTypeOptions`
      (`List<TicketLinkType>`) param; `onSelected`'s signature changes
      from `ValueChanged<Ticket>` to `void Function(Ticket, TicketLinkType)`
      (design.md §4.1). The overlay header row gains a leading
      `SelectionMenu<TicketLinkType>` (same trigger pattern as the
      priority/complexity/type/status pickers in
      `ticket_metadata_section.dart`), defaulting to
      `TicketLinkType.relatesTo`, restricted to `linkTypeOptions`;
      `_commit` passes `(ticket, currentlySelectedLinkType)`. Update the
      class's dartdoc for the new param/signature. Per Component Spec
      §1 "LinkTypeSelector" (§1.1-§1.7: trigger geometry/states, per-
      type glyph+copy, open-menu panel/item states) and §0's overlay-
      header placement (selector row above the existing search field).
- [x] T14. `features/tickets/presentation/widgets/ticket_metadata_section.dart`
      — widen the Linked Tickets type gate from `resource`/`bug`-only to
      exclude only `page`/`chat`/`signal`/`release` (design.md §4.2);
      the `TicketLinkPicker` call site passes `linkTypeOptions: [relatesTo]`
      for `resource` (unchanged one-tap behavior) and `[blocks,
      blockedBy, relatesTo, duplicates]` for `epic`/`story`/`task`/`bug`;
      `onSelected` forwards the chosen `linkType` to `createLink`
      instead of the hardcoded `relatesTo` literal, then calls
      `context.read<TicketsCubit>()._refreshBlockedBoardState()`-
      equivalent public trigger (design.md §4.2 — expose whatever
      minimal public method `_refreshBlockedBoardState` needs to be
      called from outside the cubit, e.g. reuse the existing
      `loadDocumentRelations` reload path plus a public wrapper) when
      the created type is `blocks`/`blockedBy`. Update the section's
      class dartdoc. Per Component Spec §0's per-surface placement
      table (the `LinkTypeSelector` from T13 renders unchanged here —
      no new visual spec of its own for this task).
- [x] T15. `features/tickets/presentation/cubit/tickets_cubit.dart` —
      widen `loadDocumentRelations`'s type gate from `page`/`resource`/
      `bug` to also include `epic`/`story`/`task` (design.md §4.3), so
      the now-visible Linked Tickets section on those types actually
      populates. Update the method's dartdoc.
