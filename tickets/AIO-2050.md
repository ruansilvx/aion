# T21. Create `lib/features/tickets/data/services/ticket_markdown_watcher_service.dart`

— wraps `watcher`'s `DirectoryWatcher` scoped to `<rootPath>/tickets/`,
debounces (default ~1.5s, constructor-configurable). **Corrected
from design.md**: `resource`/`page` type filtering happens inside
`TicketMarkdownReconciler.reconcile` itself (which needs the DB
lookup anyway) rather than duplicated here via a separate
ticketId->type lookup. **Fixed post-`/verify`**: `start()` was
only wiring the `DirectoryWatcher` for future events and never
performed design.md's specified immediate reconcile pass over
existing ticket files on resume, so edits made while backgrounded
were silently missed until the next live filesystem event. `start()`
now also sweeps every existing `tickets/*.md` file and calls
`reconcile` on each immediately.
