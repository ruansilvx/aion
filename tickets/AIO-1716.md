# T12. `lib/features/providers/presentation/cubit/provider_settings_cubit.dart`

— ADD: `ProviderSettingsCubit(AgentModelClient, AgentSettingsRepository)`
with `load()`, `testConnection()`, `selectModel(AgentModel)`. `load()`
reads the persisted model then immediately runs one connection test.
`testConnection()`/`selectModel()` no-op while `status == checking`
rather than racing two in-flight tests — this is the Cubit-level
domain logic per project.md's Cubit-vs-repository split. A connection
test sends a minimal `AgentRequest` (e.g. `prompt: 'ping'`) and maps
the resulting event stream to `connected`/`disconnected` +
`statusMessage`; an `AgentOverageDetectedEvent` on an otherwise
successful test sets `status: connected` with that event's message as
`statusMessage`. Per design.md §4.2. Full dartdoc, file header comment.
