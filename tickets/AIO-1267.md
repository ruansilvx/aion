# 1. Git/gitignore infrastructure

- [x] 1.1 Add `isGitRepository(String rootPath)` to
      `aion/lib/core/git/git_repository_client.dart` — checks whether
      `<rootPath>/.git` exists (file or directory; doesn't shell out to
      `git`). Document the method per project.md's per-method minimum
      (one-line summary + what "already a repo" covers, including the
      worktree/submodule `.git`-file case).
- [x] 1.2 Create `aion/lib/core/git/gitignore_editor.dart` — new
      `GitignoreEditor` class with `ensureIgnored(String rootPath,
      List<String> entries)`: reads `<rootPath>/.gitignore` if present,
      appends any `entries` not already present as exact lines, creates
      the file (with entries) if absent. File header + class dartdoc +
      method dartdoc, per project.md.
- [x] 1.3 Unit tests: `test/core/git/git_repository_client_test.dart`
      (extend — `isGitRepository` true/false cases) and new
      `test/core/git/gitignore_editor_test.dart` (create-if-absent,
      append-if-present, idempotent-if-already-present, mixed
      partially-present entries). Use a temp directory per test, mocktail
      not needed (pure file I/O).
