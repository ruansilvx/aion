# **T10a** — Create `lib/core/theme/aion_colors.dart`

Implement `AionColors` and `AionPriorityColors` exactly as specified in
design.md §1.1 and §1.2. Key rules:
- Both are `@immutable` classes with `const` constructors — **no static
constants** on the classes themselves; instances are the API.
- Declare the four instances at the top of the file as top-level `const`
values: `arcticPriority`, `obsidianPriority`, `arctic`, `obsidian`.
Order: priority instances first (referenced by color instances).
- `AionColors` fields: `background`, `surface`, `surfaceHover`, `primary`,
`primaryHover`, `primarySubtle`, `secondary`, `success`, `danger`,
`warning`, `textPrimary`, `textSecondary`, `textMuted`, `border`,
`borderStrong`, `priority` (AionPriorityColors), `typeTask`, `typeStory`,
`typeEpic`.
- `AionPriorityColors` fields: `criticalBg`, `criticalFg`, `highBg`,
`highFg`, `mediumBg`, `mediumFg`, `lowBg`, `lowFg`.
- Arctic hex values (all `Color(0xFF...)` constants):
background `0xFFEDF2F8`, surface `0xFFFBFCFE`, surfaceHover `0xFFE4EDF6`,
primary `0xFF2E86D4`, primaryHover `0xFF1E6DB6`, primarySubtle `0xFFDBE9F7`,
secondary `0xFF5E7183`, success `0xFF1E9E76`, danger `0xFFCE3D54`,
warning `0xFFB8912B`, textPrimary `0xFF142230`, textSecondary `0xFF46586A`,
textMuted `0xFF8496A6`, border `0xFFD6E0EA`, borderStrong `0xFFBAC8D6`,
typeTask `0xFF2E86D4`, typeStory `0xFF1E9E76`, typeEpic `0xFF6A5AD0`.
- Obsidian hex values:
background `0xFF0A0E18`, surface `0xFF131A29`, surfaceHover `0xFF1C2436`,
primary `0xFF9366FF`, primaryHover `0xFFA886FF`, primarySubtle `0xFF241F3E`,
secondary `0xFF57608A`, success `0xFF33D19B`, danger `0xFFF1546C`,
warning `0xFFD7B24E`, textPrimary `0xFFE7EDF7`, textSecondary `0xFFA2AEC6`,
textMuted `0xFF6B7690`, border `0xFF232C40`, borderStrong `0xFF35415C`,
typeTask `0xFF9366FF`, typeStory `0xFF33D19B`, typeEpic `0xFF5C7CF5`.
- Arctic priority: criticalBg `0xFFFBE0E5`, criticalFg `0xFFB22A41`;

`fillAlphaObsidian = 0.16`. Widgets compute tinted fills as
`c.typeTask.withOpacity(a)` — never hard-code the fill Color.
- No Material import. No `ThemeData`, `ColorScheme`, `ThemeExtension`.
