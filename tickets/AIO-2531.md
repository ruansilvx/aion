# Ticket-feature widgets

- [x] 7. Create `lib/features/tickets/presentation/widgets/trash_selection_bar.dart`
      — `TrashSelectionBar`: a `StatelessWidget` with constructor params
      `selectedCount`, `allSelected`, `onCancel`, `onSelectAll`,
      `onRestore`, `onDeleteForever` (all required). SUPERSEDES this
      task's original `AppButton`-reuse plan — the approved design
      export specifies fully bespoke Restore/Delete-forever buttons
      (custom default/hover/focused/pressed/disabled states; a
      neutral-gray, not dimmed-red, disabled treatment; a specific
      pressed-fill/hover-blend formula) that `AppButton`'s existing
      `secondary`/`destructive` variants don't reproduce, so build them
      as bespoke `GestureDetector`→`Focus`→`AnimatedContainer` widgets
      per the export, not `AppButton` instances. Two-row layout on phone
      widths (Cancel/count/Select-all row, then a Restore/Delete-forever
      row of two `Expanded` equal-width buttons); collapses to a single
      row on wide viewports via one `LayoutBuilder` switch — no separate
      component. Outer chrome (bordered/rounded/shadowed `DecoratedBox`)
      modeled on `TicketSelectionBar`'s own outer shell but duplicated,
      not shared/exported (that file's chrome widgets are private); use
      `TicketSelectionBar`'s existing shadow formula
      (`Color(0xFF000000).withValues(alpha: t.isDark ? 0.55 : 0.30)`)
      rather than the export's one-off navy-tinted shadow ARGB values.
      Delete forever's hover fill: `Color.alphaBlend(const
      Color(0xFF000000).withValues(alpha: 0.08), c.danger)` (no stored
      `dangerHover` token — a one-off computed blend). Translate every
      `.withOpacity()` in the export to `.withValues(alpha:)` for
      consistency with every existing `AionColors` extension method.
      Full dartdoc on the class and every param. (design.md §6; per
      design.md "Aion — Trash Screen Multi-Select" export §3
      `TrashSelectionBar`, §3.1–§3.7, and §0 for shared tokens/new
      constants `kCheckboxSize`/`kRowSelectAccent`/`kBarActionMinHeight`)
