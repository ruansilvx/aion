# **T8 — Add unit-test coverage for `formatRelativeTime`.**

`aion/test/core/utils/relative_time_format_test.dart`: add a new
`group('formatRelativeTime', ...)` alongside the existing
`formatTrashedAge` group (same file, same `now`-parameter pattern),
covering every bucket: `< 60s` → `'just now'`, `1m`/`59m` → `'{n}m
ago'`, `1h`/`23h` → `'{n}h ago'`, `1d`/`6d` → `'{n}d ago'`,
`7d`/`29d` → `'{n}w ago'`, `30d`+ → `'{n}mo ago'`, plus the `now`
defaulting-to-`DateTime.now()` case. See design.md §7/spec.md's
ADDED section for why this pre-existing gap is closed as part of
this change.
