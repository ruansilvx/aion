# Thread a ticketsRootPath choice through CreateProjectCubit

Add a new parameter to `CreateProjectCubit.submit` (e.g.
`separateTicketsRepo: bool = false`) alongside the existing
`appendGitignore`. When `true` and running on desktop,
`_initializeDesktopProject` additionally sets up a local-only tickets
repo at `<rootPath>/.aion/tickets-repo` (`git init`, no remote --
out of scope per the epic), and the created `Project`'s
`ticketsRootPath` is set to that path. `false` (the default) changes
nothing -- `ticketsRootPath` stays unset, matching today's behavior
exactly. No UI in this task -- purely the cubit/domain-layer plumbing
and its tests. Not blocked by the design gate below.
