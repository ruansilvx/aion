- [x] **T5.** Create `lib/features/tickets/domain/utils/ticket_sort_comparator.dart`
  — the shared `ticketFieldEnumValues` ordinal-lookup constant plus

  descending (no query to score against in a pure in-memory comparator).
  File header + dartdoc on the constant and the function.
