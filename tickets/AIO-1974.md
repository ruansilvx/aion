# Outcome glyph (design.md §0.1) — implemented as a new shared

`TransitionOutcomeGlyph` `CustomPaint` widget
(`transition_node_form.dart`, public since the other two
consumers import that file already) and wired into all three
mandated consumers: the canvas terminal pill
(`_CanvasNodeContent` in `sddstage_precondition_editor_screen.dart`,
12×12 per §1.3), the outline badge (`_OutcomeBadge` in
`transition_outline_list.dart`, 10×10 with §2.2's literal
`1.8`/`1.4` stroke widths), and the form's outcome chip
(`_OutcomeChip` in `transition_node_form.dart`, 11×11 per §3.3).
Also added `_OutcomeBadge`'s missing §2.2 `MATCHED`/`UNMATCHED`
branch-word prefix, abbreviated to `M`/`U` via a `LayoutBuilder`
measuring the row's own available width against the `360`px
threshold (not the outline pane's gross width, which isn't
locally available at that widget — the row's own constraint is
what's actually cramped).
