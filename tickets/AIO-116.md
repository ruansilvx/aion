# T3. `lib/core/agent/anthropic_messages_api_client.dart` — ADD:

`AnthropicMessagesApiClient implements AgentModelClient`, constructed
with a `Dio` and a `Future<String?> Function()` API-key getter.
`run()`: returns an immediate `AgentErrorEvent` if `toolsEnabled` is
`true` (unsupported) or no API key is available; otherwise POSTs to
`https://api.anthropic.com/v1/messages` with `stream: true`, parses
the SSE response into `AgentTextEvent`/`AgentDoneEvent` (reading
`usage.input_tokens`/`usage.output_tokens` off `message_start`/
`message_delta`), maps a `429` response to `AgentOverageDetectedEvent`
instead of `AgentErrorEvent`, and maps any other non-2xx/error frame
to `AgentErrorEvent`. Per design.md §2. Depends on T1. Full dartdoc,
file header.
