# T12. **(WARNING fix)** `TicketParentPicker`'s form-field trigger

(`aion/lib/features/tickets/presentation/widgets/ticket_parent_picker.dart`)
was missing the Disabled and Error states specified in design.md's
Component Spec §2.3. Added `isDisabled`/`errorText` constructor
params: `isDisabled` renders 50% opacity + blocks
opening/interaction (`IgnorePointer`) and is wired from
`CreateTicketScreen` to `_isSubmitting`; `errorText` renders a
danger-colored border/ring plus a helper `Text` line below the
control when non-null (no current caller sets it — create-time
`parentId` still isn't validated by the Cubit — but the rendering
path now exists per spec). Dartdoc added on both new fields.
