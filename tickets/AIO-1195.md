# 4.4 `data/repositories/bundled_baseline_repository.dart` —

`BundledBaselineRepository implements BaselineRepository`. Reads
`assets/baseline/<version>/manifest.json` via Flutter's asset
bundle; lists `<rootPath>/.aion/overrides/` files for
`readOverrides` (desktop only — returns `[]` when `rootPath` is
null). Header + dartdoc.
