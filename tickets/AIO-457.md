# Presentation layer — cubit

- [x] 5. Modify `lib/features/tickets/presentation/cubit/tickets_cubit.dart`
      — add `updateStatusForTickets(List<String> ids, TicketStatus status)`:
      per-id gate filtering (only when `status == TicketStatus.inProgress`,
      via `_isTicketBlocked` and, for executable types,
      `_codingExecutionGateCheck`), bulk write of the writable subset via
      `_repository.updateStatusForIds`, per-written-ticket git-projection
      trigger (`'status-changed'`) and coding-execution
      trigger/queue (Task/Bug moving to `inProgress` only), refreshed-page
      re-fetch (`_lastQuery`/`_lastStatuses`/`_lastTypes`/`_lastPriorities`,
      `max(_pageSize, currentTickets.length)`), `_refreshBlockedBoardState()`
      call, `TicketsBatchStatusUpdating`/`TicketsBatchStatusUpdated`
      emission, `TicketsError` on failure. Full dartdoc, cross-referencing
      `updateTicketStatus`. (design.md §5.1)

      — add `updatePriorityForTickets(List<String> ids, TicketPriority priority)`:

      refreshed-page re-fetch (same pattern as task 5, no blocked-board

      already lists `TicketsBatchTrashed`). (design.md §5.1, §5.2)
