# T24. Create `lib/features/tickets/data/services/ticket_db_reconstruction_service.dart`

— `TicketDbReconstructionService.reconstruct(rootPath)`: walks
`tickets/*.md`, parses each via T15, upserts via
`TicketRepository`, skips/reports unparseable files, then bulk-
triggers `EmbeddingProvider` for every imported ticket lacking an
embedding. Returns a `TicketReconstructionReport`. **Known
limitation documented inline**: `TicketRepository.createTicket`
always assigns a fresh sequential `ticketId`, ignoring the one on
the passed `Ticket` — so importing a file with no matching
existing row doesn't actually preserve the `ticketId` the file is
named after. Fixing needs a repository-level change out of scope
here; flagged rather than silently shipped as if it round-trips.
