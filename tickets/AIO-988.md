# **T20** — Modify `lib/design_system/molecules/

markdown_editor.dart`: add optional `List<WikilinkSuggestionItem>
Function(String query)? wikilinkSuggestions` and `Future<
WikilinkSuggestionItem?> Function(String title)? onCreatePage`
constructor parameters. `TextEditingController` listener detects an
in-progress `[[<query>` span (just-typed `[[`, no closing `]]` yet on
the current line); when `wikilinkSuggestions != null`, opens a
`WikilinkSuggestionList` inside an `Overlay`/`LayerLink`/
`CompositedTransformFollower` **anchored to the live text caret
position** (a `LayerLink` pinned to the `[[` insertion point,
flipping above the caret if the panel would overflow the viewport
bottom — build this for real per design.md §4.1, not the
field-anchored MVP simplification originally proposed),
`Escape`/outside-tap-dismissible. On selection, replaces the
in-progress span with **`[[<ticketId>]]`** (bare, no alias — not
`[[<Title>]]`) and moves the cursor past the closing brackets. In the
no-matches state, pressing Enter calls `onCreatePage(query)` (when
supplied) and inserts its result the same way; `null`/no callback
leaves Enter a no-op there. Update dartdoc to describe both new
optional behaviors and their `null` no-op cases. Per design.md §4.1
(panel chrome, caret anchor/overflow-flip behavior), §4.5
(create-on-the-fly), and §1.4 (bracket-pair glyph).
