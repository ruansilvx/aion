# Spec delta: trash-age-and-manual-purge

**Reconciled 2026-09-03:** confirmed against the current `aion-arch/specs/tickets.md` "Trash & bulk delete" section — `purgeTrashOlderThan`, `TrashCubit.purgeAgeThreshold` (30-day default), `purgeOldTrash()`, and the manual "Purge old" action this delta introduces all still match current text exactly. Flagged-missing items are l10n key names the current prose describes functionally rather than by literal key. No drift.

Applies to `aion-arch/specs/tickets.md`'s "Trash & bulk delete" section
and its `Ticket` entity table.

## ADDED

- **`TicketRepository`/`DriftTicketRepository`:**
  `purgeTrashOlderThan(Duration age) → Future<int>` — permanently
  deletes every currently trashed ticket whose `deletedAt` is older than
  `age`, cascading to comments and `ticket_links` exactly like
  `emptyTrash()`. Returns the number of tickets purged; `0` if none
  qualify. Filters individual trashed rows directly (no cascade/subtree
  walk needed) — a trashed subtree's members always share one
  `deletedAt`, stamped together by whichever trash cascade last touched
  them, and no UI path re-trashes a single already-trashed descendant
  independently, so a root and its descendants always age out as a
  group.

- **`core/utils/relative_time_format.dart`:** `formatTrashedAge(DateTime
  deletedAt, {DateTime? now})` — pure function returning a short,
  unlocalized "Trashed …" label (today / yesterday / N days ago / N
  weeks ago / N months ago). Same treatment as the existing
  `formatDurationMinutes`: called directly from presentation-layer
  `Text` widgets, no `l10n` ARB entry (consistent, not a violation of
  the localization rule — see that helper's existing use in
  `ticket_detail_screen.dart`).

- **`TrashCubit.purgeAgeThreshold`** — `static const Duration(days:
  30)`. Fixed; not user-configurable.

- **`TrashCubit.purgeOldTrash()`** — calls
  `TicketRepository.purgeTrashOlderThan(purgeAgeThreshold)`, then
  reloads. Emits `TrashError` on failure, same shape as `emptyTrash()`.

- **`TrashedTicketTile`** now shows an age label (e.g. "Trashed 12 days
  ago") next to the type chip / "+N subtasks" text, via
  `formatTrashedAge(ticket.deletedAt!)`.

- **`TrashScreen`** header gains a "Purge old" action, left of "Empty
  trash". Disabled (matching `_EmptyTrashAction`'s pattern) when
  `purgeEligibleCount == 0`. Confirms via the same destructive-toned
  `showAppConfirmDialog` used by "Empty trash" and per-row "Delete
  forever", stating the exact count and the 30-day threshold. Calls
  `TrashCubit.purgeOldTrash()` on confirmation.

- New `l10n` keys: `ticketTrashPurgeOldAction`,
  `ticketTrashPurgeOldConfirmTitle`, `ticketTrashPurgeOldConfirmMessage`
  (placeholders: `count` int, `days` int).

## MODIFIED

- **`TrashState.TrashLoaded`** — gains a third field,
  `purgeEligibleCount` (`int`): how many currently trashed tickets
  (roots and descendants combined) are older than
  `TrashCubit.purgeAgeThreshold`. Constructor becomes
  `TrashLoaded(tickets, descendantCounts, purgeEligibleCount)`.

- **`TrashCubit.load()`** — in addition to its existing root/descendant
  reduction, also computes `purgeEligibleCount` from the full trashed
  list it already fetches (no extra repository call).

## Known gap resolved

This change narrows, but does not fully resolve, the Known Gaps bullet:

> "No automatic/timed purge of Trash (e.g. auto-delete after 30 days) —
> Trash is manual-only: items stay until the user restores or
> permanently deletes them."

Trash remains manual-only — no automatic/background purge exists after
this change. What changes: the user now has visibility (age label) and
a one-click way (Purge old) to clear out stale trash, instead of no
tooling at all. Automatic/timed purge itself remains an open gap.
