# T3. `features/tickets/presentation/widgets/chat_message_bubble.dart`

— new file, `ChatMessageBubble extends StatelessWidget` (design.md
§1 `ChatMessageBubble`): adapted from `CommentTile`'s existing
author-label/timestamp/bubble/"via `<model>`" structure. Bubble
max-width capped via `LayoutBuilder` + `ConstrainedBox` at **82%**
of available width for human messages, **88%** for ai/system
(§1.0) — never full-width. Bubble radius `16` on three corners,
`5` on the tail corner: human's tail is bottom-right, ai/system's
is top-left (§1.0). Human: right-aligned, `surface` fill + 1px
`borderStrong`, plain `Text` (§1.1). AI: left-aligned,
`primarySubtle` fill + 1px `aiBubbleBorder` (existing
`AionColorsHubTokens` helper), `MarkdownView(source: comment
.content)`, `"AI"` badge (§1.2). System: left-aligned,
`surfaceHover` fill + 1px `border`, plain `Text`, no badge
(§1.3). Reuses `_Avatar` from `ticket_detail_screen.dart` as-is
(avatar-disc geometry per §1.0: `30×30`, sparkle/diamond/`"U"`
per author type — confirm `_Avatar`'s existing sizing matches or
adjust its call site, no changes to `_Avatar` itself needed
beyond that). Markdown-in-bubble node treatments (headings, code
blocks, lists, blockquote, table) per §1.5. File header + full
class/method dartdocs.
**Deviation:** `_Avatar` was private to `ticket_detail_screen
.dart`, unreachable from this new file as-is — promoted to a
public `CommentAuthorAvatar` in its own new file,
`presentation/widgets/comment_author_avatar.dart` (same geometry,
unchanged), used by both this widget and the existing
`CommentTile`.
