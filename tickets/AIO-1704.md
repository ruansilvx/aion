# Node.js bridge (not part of the Flutter build)

- [x] T3. `agent_bridge/package.json` — new Node project declaring
  `@anthropic-ai/claude-agent-sdk` as a dependency. Per design.md §3.
- [x] T4. `agent_bridge/index.mjs` — reads one JSON request line
  (`{prompt, model}`) from stdin, calls `query()` from
  `@anthropic-ai/claude-agent-sdk` with the requested model and a
  no-tool-access `permissionMode` (this MVP has no coding-execution
  caller — see design.md §3), writes one NDJSON line per SDK event to
  stdout in the `{"type":"text"|"done"|"error"|"overage", ...}` shape
  `ClaudeAgentSdkClient` (T6) parses. Not a Dart file — a short header
  comment explaining its purpose and the NDJSON protocol suffices, no
  dartdoc.
