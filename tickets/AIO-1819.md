# Linux packaging

- [x] T3. Create `aion/linux/packaging/aion.desktop` — standard
      freedesktop `.desktop` entry for Aion (Name, Exec, Icon, Type,
      Categories) used by `linuxdeploy` to build the AppImage's desktop
      integration.
- [x] T4. Create `aion/linux/packaging/build_appimage.sh` — shell script:
      downloads pinned `linuxdeploy` and `appimagetool` AppImages if not
      already cached, stages an `AppDir/` from
      `build/linux/x64/release/bundle/`, runs `linuxdeploy` (bundling
      GTK3 shared libs the Flutter linux runner depends on) against
      `aion.desktop` and an app icon, then runs `appimagetool` to
      produce `Aion-<version>-x86_64.AppImage`. Takes the version as a
      script argument/env var, matching how T2's Inno Setup script
      receives its version define — no version hardcoded in either.
