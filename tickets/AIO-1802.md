# **T15** — `aion/lib/features/tickets/domain/entities/release_draft.dart`:

add `releaseKey` (the release ticket's display id, e.g. `"AIO-51"`) and
`targetBranch` (the branch `confirmRelease` will commit/push/tag
against) fields to `ReleaseDraft`, both required, both dartdoc'd (per
design.md §0.2's `ReleaseDraft` contract — `releaseKey`/`targetBranch`
are the two fields the architecture-section §3 shape omitted but the
UI export's own contract requires; resolve the discrepancy in favor of
the export since the scope strip and confirm dialog below both need
real values, not placeholders). Update `equatable`'s `props`. In
`tickets_cubit.dart`, `prepareReleaseDraft` populates `releaseKey` from
the release ticket's own `ticketId`, and `targetBranch` via
`GitRepositoryClient.defaultBranch(_projectRootPath!)` — the same
method `confirmRelease` already calls, so the branch shown during
review is guaranteed to match the branch actually pushed to. Dartdoc
update on `prepareReleaseDraft` noting the new fields.
