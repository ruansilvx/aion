  remove `TicketDeleting`, `TicketDeleted`, `TicketsErrorReason.hasChildren`,
  and `TicketsError.childCount` (update `TicketsError`'s constructor/
  dartdoc/`props` accordingly). Add `TicketTrashing`, `TicketTrashed`,
  `TicketsBatchTrashing`, `TicketsBatchTrashed` (carrying `tickets` +
  `trashedCount`), each with dartdoc. Per design.md §5.
- [x] T13 — `lib/features/tickets/presentation/cubit/tickets_cubit.dart`:
  remove `deleteTicket`. Add `previewTrashCount(List<String> ids)`
  (reusing the existing private `_descendantIds` helper),
  `trashTicket(String id)` (context-aware on previous state, same
  branching shape the old `deleteTicket` had, minus the blocking
  branch), `trashTickets(List<String> ids)`. Dartdoc on each. Per
  design.md §5.
- [x] T14 — Create `lib/features/tickets/presentation/cubit/ticket_selection_state.dart`:
  `TicketSelectionState extends Equatable` with `isActive`,
  `selectedIds`, and a `TicketSelectionState.initial()` const
  constructor. File header + full dartdoc. Per design.md §6.
- [x] T15 — Create `lib/features/tickets/presentation/cubit/ticket_selection_cubit.dart`:
  `TicketSelectionCubit extends Cubit<TicketSelectionState>` with
  `enter()`, `clear()`, `toggle(String id)` (add/remove from
  `selectedIds`, no-op while inactive), `selectAll(List<String> ids)`
  (selects all when not all of `ids` are already selected, deselects
  all otherwise; empty `ids` is a no-op-shaped all-deselected result).
  No relationship/invariant-checking logic — plain id-set toggling
  only, per design.md §6. File header + full dartdoc.
- [x] T16 — Create `lib/features/tickets/presentation/cubit/trash_state.dart`:
  `TrashState` sealed hierarchy — `TrashLoading`, `TrashLoaded(List<Ticket>
  tickets)`, `TrashError(String message)`. File header + full dartdoc.
  Per design.md §8.
- [x] T17 — Create `lib/features/tickets/presentation/cubit/trash_cubit.dart`:
  `TrashCubit extends Cubit<TrashState>` with `load()`, `restore(String
  id)`, `permanentlyDelete(String id)`, `emptyTrash()` — each
  non-load method re-calls `load()` on success, emits `TrashError` on
  failure. File header + full dartdoc. Per design.md §8.
