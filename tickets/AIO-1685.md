# 7. Override-authoring UI

- [x] Create `lib/features/projects/presentation/cubit/
      overrides_cubit.dart` / `overrides_state.dart` —
      `OverridesCubit`/`OverridesState` per design.md §8, full dartdoc.
- [x] Create `lib/features/projects/presentation/cubit/
      override_editor_cubit.dart` / `override_editor_state.dart` —
      `OverrideEditorCubit`/`OverrideEditorState` per design.md §8.
- [x] Create `test/features/projects/cubit/overrides_cubit_test.dart` and
      `test/features/projects/cubit/override_editor_cubit_test.dart`.
- [x] Create `lib/features/projects/presentation/screens/
      overrides_list_screen.dart` — `OverridesListScreen`. Simplified
      relative to the full Claude Design spec: no stat line on the list
      header (would need `OverridesCubit` data plumbed into
      `SettingsScreen` too, for a single number of limited value), and
      per-row descriptors are derived mechanically from the asset-key
      segment rather than 15 hand-written strings. Kind icon well,
      "Overridden" chip (using the new `aiBubbleBorder(isDark)` token),
      and empty state are implemented per the Claude Design spec's
      shapes/tokens.
- [x] Create `lib/features/projects/presentation/screens/
      override_editor_screen.dart` — `OverrideEditorScreen`, using
      `AppTextField(maxLines: null)` for the editor rather than a
      bespoke `_OverrideTextEditor` (Aion's own established "one
      Material `TextField`, always wrapped" precedent — see
      `AppTextField`'s own dartdoc — so no new primitive was needed).
      Status-line variant A uses the new `aiBubbleBorder(isDark)` token;
      variant B reuses the existing `noticeFill`/`noticeBorder` helpers.
      Save button label switches between "Save override"/"Create
      override" per `isOverridden`, disabled while pristine or saving.
      Reset-to-default and discard-with-unsaved-changes are out of
      scope per proposal.md.
- [x] Update `lib/features/providers/presentation/screens/
      settings_screen.dart` — add the new "OVERRIDES" eyebrow +
      `_OverridesSummarySection` linking to
      `/workspace/settings/overrides`. Simplified: summary + button only,
      no stat line (see the list-screen simplification note above).
- [x] Update `lib/core/routing/app_router.dart` — register
      `/workspace/settings/overrides` (`OverridesListScreen`, its own
      route-scoped `BlocProvider<OverridesCubit>`) and
      `/workspace/settings/overrides/:assetKey` (`OverrideEditorScreen`,
      route-scoped `BlocProvider<OverrideEditorCubit>`), matching
      `TrashScreen`'s existing route-scoping pattern. Also updated
      `lib/features/projects/projects.dart`'s barrel to export the four
      new cubit/state/screen files.
- [x] Add new `lib/l10n/app_en.arb` keys for the Overrides UI:
      `settingsOverridesEyebrow`, `settingsOverridesSummary`,
      `settingsOverridesManageButton`, `overridesListTitle`,
      `overridesListEmptyState`, `overridesListOverriddenChip`,
      `overrideEditorTitle`, `overrideEditorDefaultNotice`,
      `overrideEditorOverriddenNotice`, `overrideEditorSaveButton`,
      `overrideEditorCreateButton`, `overrideEditorSavingLabel`. The
      Save/Create split flagged during design-sync is resolved with two
      separate keys (`overrideEditorSaveButton`/
      `overrideEditorCreateButton`) rather than a parameterized string.
