# T4. In the same file, add an optional `breadcrumb` field to

`_CandidateRow` and render it as a second `Text` line
(`AionText.caption`, `c.textMuted`, `maxLines: 1`,
`TextOverflow.ellipsis`) below the existing ticketId/title row,
omitted entirely when `breadcrumb` is null. The overlay's
`ListView.builder` (now in this file) computes a `byId` map once
per build from the fetched candidate list and passes
`ancestorBreadcrumb(candidate, byId)` into each row.
per design.md "Changes §4" and Component Spec §3.0 "Row structure"
/ §3.1 "Breadcrumb text style" / §3.2-§3.4.
CORRECTION: use the new `AionText.breadcrumb` style (Manrope 11 /
w500 / ls 0, color `textMuted`), NOT `AionText.caption` as written
above — Component Spec §3.1 explicitly rejects `caption` for this
row (its uppercase/wide-tracking reads badly on a mixed-case
breadcrumb path). Row layout also changes per Component Spec §3.0:
`crossAxisAlignment: start` (not `center`), leading key gets
`SizedBox(width: 52)` + `padding-top: 1`, center column is a
`Column` with `gap: 2` (title, then breadcrumb), trailing type
square `8×8` radius `2` with `margin-left: 8` + `padding-top: 4`.
`AionText.breadcrumb` must be added to
`aion/lib/design_system/tokens/aion_text.dart` first — see Step 2
of the design-sync report for the exact constant.
