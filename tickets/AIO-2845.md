# Add an optional tickets-repo location to the Project model

New optional field on `Project` (registry DB + wherever `.aion/` project
config persists) for a tickets-repo path, distinct from `rootPath`.
Default unset -- no behavior change for any existing project until it's
explicitly set. No UI yet; this story is the data-model/persistence
layer only.
