# Add an optional tickets-repo location to the Project model

New optional field on `Project` (registry DB + wherever `.aion/` project
config persists) for a tickets-repo path, distinct from `rootPath`.
Default unset -- no behavior change for any existing project until it's
explicitly set. No UI yet; this story is the data-model/persistence
layer only.

## Technical shape

Four layers, in dependency order:

1. **Domain entity** (`lib/features/projects/domain/entities/project.dart`)
   -- add `ticketsRootPath` (nullable `String`, desktop-only like
   `rootPath`) to `Project`: constructor param, field, `props`.
2. **Persistence schema** (`lib/core/database/registry_database.dart`)
   -- add a nullable `ticketsRootPath` text column
   (`.named('tickets_root_path')`) to `ProjectsTable`. `RegistryDatabase
   .schemaVersion` is currently `1` with only an `onCreate` migration (no
   `onUpgrade` yet) -- bump to `2` and add the `onUpgrade` step
   (`m.addColumn(projectsTable, projectsTable.ticketsRootPath)`),
   additive and backward compatible (existing rows get `NULL`).
3. **Data model + repository**
   (`lib/features/projects/data/models/project_model.dart`,
   `lib/features/projects/data/repositories/drift_project_repository.dart`,
   `lib/features/projects/domain/repositories/project_repository.dart`)
   -- thread the new field through `ProjectModel.fromRow`/`fromEntity`/
   `toEntity`/`toCompanion`, and add
   `updateTicketsRootPath(String id, String? path)` to
   `ProjectRepository`/`DriftProjectRepository`, matching the existing
   per-field update-method pattern (`updateLastOpened`,
   `updateBaselineVersion`) rather than a generic update-any-field method.
4. **Tests** -- round-trip coverage across entity equality, model
   fromRow/fromEntity/toEntity/toCompanion, the schema migration
   (`1 -> 2`, existing row survives with `NULL`), and the new repository
   method, matching this codebase's existing test file layout
   (`test/features/projects/...` mirroring `lib/features/projects/...`).

No UI, no wiring into `TicketGitProjector`/`GitRepositoryClient`/etc. in
this story -- that's AIO-2846.
