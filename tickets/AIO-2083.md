# Chat-turn plumbing

- [x] T4. In
  `lib/features/tickets/presentation/cubit/chat_cubit.dart`: add
  `toolsEnabled` (`bool`, default `false`), `workingDirectory`
  (`String?`, default `null`), and `onOverageDetected` (`void
  Function()?`, default `null`) parameters to the static `runChatTurn`,
  threading the first two into the `AgentRequest` it builds and calling
  the third from the existing `AgentOverageDetectedEvent` case (in
  addition to its current no-op). Change the `AgentErrorEvent` case to
  also capture the event's `message` into a local `failureMessage`
  variable. After the loop, when `!succeeded`, persist one
  `CommentAuthorType.ai` comment (`'Execution failed:
  ${failureMessage ?? 'unknown error'}'`) instead of persisting nothing,
  per `design.md` §2. Update `runChatTurn`'s dartdoc to describe the new
  params and the failure-comment behavior; update `sendMessage`'s dartdoc
  if its described behavior on failure changes as a result (it does not —
  `sendMessage` already emits `ChatError` separately, this only affects
  what gets persisted to the transcript).
