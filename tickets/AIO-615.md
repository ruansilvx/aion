# Capture `message.session_id` the first time any message in the

`query()` loop carries it; emit `{"type":"session","sessionId":"..."}`
once, before processing that same message's `tool_use`/other
content (so a `tool_call_request` line the same message batch
produces is never emitted before the session line). Read new
optional `resume`/`forkSession` fields off the initial request
line (`readRequest()`'s destructured shape); when `resume` is
present, pass `{resume, forkSession}` into `query()`'s `options`
alongside `model`. Update the file's top-of-file comment block
(the NDJSON event-shape list) to document the new `"session"`
line. Per design.md §3 — no `resumeSessionAt` (deliberately
omitted; see design.md §1 finding 3 for why).
