# T6. `lib/core/agent/claude_agent_sdk_client.dart` — ADD:

`ClaudeAgentSdkClient implements AgentModelClient`, constructed with
an `AgentBridgeLocator`. `run()` spawns `node <resolved script path>`
via `Process.start`, writes the JSON request to stdin, parses NDJSON
stdout into `AgentEvent`s (private `_parseLine` helper). A
`Process.start` failure (e.g. `node` not on `PATH`) surfaces as a
single `AgentErrorEvent` with a human-readable message, not a thrown
exception, per design.md §2. Full dartdoc, file header comment.
