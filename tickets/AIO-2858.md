# Design — Offer the choice at project-creation time

# AIO-2857 — separate tickets repo on `NewProjectScreen`

Design spec for `/design-sync`. Companion mockups: `Aion Separate Tickets Repo Mockups.dc.html`.
Revised against the corrected brief: the tickets repo can take an **optional remote URL**, so the banner gains a text field as well as a checkbox.

## 0. Scope and files touched

**This is an edit to one existing widget — no new files.**

| File | Change |
|---|---|
| `GitignoreConfirmationBanner` (existing) | Extended: body copy replaced; checkbox row becomes a two-row divided choice group; a revealed remote-URL field nests under the second row; gitignore label and unchecked hint become state-dependent. |
| `NewProjectScreen` | No structural change. It already hosts the banner between the Location picker and Baseline version; it now also carries `separateTicketsRepo` and `ticketsRepoRemoteUrl` through the form controller into `CreateProjectCubit.submit`. |
| `app_en.arb` | 13 new keys (Before/After splits where a path chip is inline), 3 existing kept, the 3-key banner-body split retired (§5). |

No new sibling widget. Both choices are the same first-run decision and share the banner's notice tone, icon chip and 39px left gutter.

**Resolved open questions**

1. **Peers, not nested.** Two independent checkbox rows inside one divided group (Option A). A separate tickets repo is legal with gitignore off, so nesting (Option B) asserts a dependency the cubit does not have. The relationship shows up in **copy**: turning the tickets repo on rewrites the gitignore label from `.aion/` and `tickets/` to just `.aion/`, and narrows the unchecked hint to match.
2. **Remote field appears with the checkbox** (R1), not behind an "Add a remote…" link (R2). The checkbox is already the progressive disclosure; a second click to reach an optional field hides the exact thing a user with a prepared repo came to paste. `AppTextField`'s own `isOptional` marker plus the blank-state helper keep it from reading as required.
3. **Explanatory copy:** one muted caption under the new checkbox (it names the path), plus the field's own label and helper line. The banner body is generalised to cover both choices; the old body text naming `.aion/` and `tickets/` is retired since those paths now appear in the labels beneath it.
4. **Default off** for `separateTicketsRepo`, matching its own default. Gitignore stays default on. Remote URL starts empty.

## 1. Tokens

No new colors, radii, spacing or type tokens, with one exception: a divider tint in the existing `primary`/notice family, following the `AionColorsHubTokens` derived-tint pattern.

```dart
// primary family — hairline between the two choice rows inside a notice card
Color noticeDivider(bool isDark) =>
    primary.withValues(alpha: isDark ? 0.22 : 0.16);
```

Everything else reuses `noticeFill` / `noticeBorder` / `noticeIconTint`, `AionRadius.lg`/`sm`, `AionSpacing`, and `AionText.cardTitle` / `body` / `bodySm` / `key`.

## 2. Widget structure

Outer container, message row, icon chip and the 39px left gutter are **unchanged** from the current banner (see `Aion Attach Existing Repo Spec.md` §2.0–2.1). Only the contents below the message row change.

```dart
Container(                                     // unchanged geometry
  padding: const EdgeInsets.fromLTRB(15, 14, 15, 14),
  decoration: BoxDecoration(
    color: c.noticeFill(isDark),
    border: Border.all(width: 1, color: c.noticeBorder(isDark)),
    borderRadius: BorderRadius.circular(AionRadius.lg),
  ),
  child: Column(
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      _MessageRow(),                           // §2.1
      const SizedBox(height: AionSpacing.sp12),
      Padding(                                 // §2.2 choice group
        padding: const EdgeInsets.only(left: 39),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            _GitignoreChoiceRow(),             // §2.3
            const SizedBox(height: 11),
```

All four `_`-prefixed widgets are private to the existing banner file — not exported components.

### 2.1 Message row (copy change only)

Icon chip (28×28, `noticeIconTint`, Phosphor `GitBranch` Light @17, `AionColors.primary`) and title unchanged:

- Title — `AionText.cardTitle`, `textPrimary`, `height: 1.35`: "This folder is already a Git repository" (`newProjectGitignoreBannerTitle`, existing, unchanged).
- Body — `AionText.bodySm`, `textSecondary`, `height: 1.5`: now `newProjectRepoChoicesBody` (§5) — a **single** string, since the new copy has no path chips in it. This retires the existing `newProjectGitignoreBannerBodyBefore` / `...Middle` / `...After` split, whose only reason to exist was the `.aion/` and `tickets/` chips; those paths now live in the labels below.

### 2.2 Choice group

`Column`, `crossAxisAlignment: start`, inside `EdgeInsets.only(left: 39)` (unchanged gutter: 28px chip + 11px gap). Rows separated by `11 / 1px divider / 11`. The divider spans the group's width — starting at the checkbox, not the card edge — so it groups the rows as siblings without boxing them.

### 2.3 Gitignore row (existing control, dynamic label)

`Row`, `crossAxisAlignment: center`, `gap: 10`.

- `AppCheckbox` at 18×18, bound to `excludeAionPaths`, **checked by default**. All states per `Aion Attach Existing Repo Spec.md` §2.2 — unchanged, not redesigned.
- Label — `AionText.body.copyWith(fontWeight: FontWeight.w500, color: textPrimary)`, built as a `RichText` of l10n `TextSpan`s with inline `WidgetSpan` path chips (`AionText.key`-sized: JetBrains Mono 12 / w600, `textSecondary`, **no fill**):
  - `separateTicketsRepo == false` → the existing `newProjectGitignoreCheckboxLabelBefore` / `...Middle` / `...After` split, unchanged: "Add " · `.aion/` · " and " … → "Add `.aion/` and `tickets/` to `.gitignore`"
  - `separateTicketsRepo == true` → a new Before/After pair, `newProjectGitignoreCheckboxLabelAionOnlyBefore` / `...After` → "Add `.aion/` to `.gitignore`" (§5)
- Tapping the label toggles the checkbox (same `GestureDetector` as today).
- The label swap animates: `AnimatedSize` + `FadeTransition`, `160ms`, `Curves.easeOut` — not an instant text pop, since the pointer is on the *other* checkbox when it happens.

### 2.4 Separate-tickets-repo row (new)

`Row`, `crossAxisAlignment: start`, `gap: 10`.

- `AppCheckbox` at 18×18, `margin: EdgeInsets.only(top: 1)` (optically centers on the label's first line), bound to `separateTicketsRepo`, **unchecked by default**. Same `AppCheckbox`, same states. Never a Material `Checkbox`.
- Text block — `Expanded`, `Column`, `crossAxisAlignment: start`, `gap: 3`:
  - Label — same style as §2.3: `newProjectSeparateTicketsRepoLabel` — "Keep tickets in their own repository".
  - Caption — `AionText.bodySm.copyWith(fontSize: 12, color: textMuted)`, `height: 1.45`, also a `RichText` with a `WidgetSpan` chip for `.aion/tickets-repo` (`AionText.key`-sized: JetBrains Mono 11.5 / w600, `textSecondary`, no fill). Keys: `newProjectSeparateTicketsRepoHintBefore` / `...After` (§5).
- The whole text block is tappable and toggles the checkbox, matching §2.3.
- The caption does **not** claim the repo is local-only — that depends on §2.5 and is stated there.

### 2.5 Remote-URL field (new, revealed)

Rendered only when `separateTicketsRepo == true`, in a `Column` at `EdgeInsets.only(left: 28)` — indented to the second checkbox's text block (18px box + 10px gap) so it reads as belonging to that row.

**Input** — `AppTextField` (this project's sanctioned text-field primitive; it wraps a Material `TextField` internally, the one allowed exception), bound to `ticketsRepoRemoteUrl`, **at its existing fixed styling — no new compact variant is needed or requested**:

```dart
AppTextField(
  controller: ticketsRepoRemoteUrlController,
  labelText: l10n.newProjectTicketsRepoRemoteLabel,   // "Remote URL"
  isOptional: true,                                   // renders commonOptionalMarker
  hintText: l10n.newProjectTicketsRepoRemotePlaceholder,
  style: AionText.key.copyWith(fontWeight: FontWeight.w400),
  keyboardType: TextInputType.url,
)
```

- The component owns its own label placement, "Optional" marker (via `commonOptionalMarker` — **no new key, no hand-built qualifier row**), geometry (`AionRadius.lg` corners, `EdgeInsets.symmetric(horizontal: 14, vertical: 12)`) and focus treatment (`AionShadows.focus` — a shadow, not a border+ring). None of that is restyled here.
- The only deviation from a default `AppTextField` is `style`: the value is a URL, so pass `AionText.key` (JetBrains Mono) for the entered text and hint rather than the default Manrope body.
- Single line; overflow ellipsises. No validation — non-empty is the only condition the cubit cares about, so **no error state is designed**. `AppTextField.isError` already exists if validation lands later.

The field's own label/marker means the revealed block is just: `AppTextField` → `SizedBox(height: 6)` → helper row.

**Helper row** — `Row`, `crossAxisAlignment: start`, `gap: 6`. Phosphor `Info` Light @12 in `textMuted`, `margin: top 1`; text `AionText.bodySm.copyWith(fontSize: 11.5, color: textMuted)`, `height: 1.4`. Copy switches on whether the field has content:
- empty → `newProjectTicketsRepoRemoteHintBlank` — "Leave blank to keep the repository on this machine only." (single string, no chip)
- non-empty → `newProjectTicketsRepoRemoteHintSetBefore` / `...After` — "Set as `origin` on the new tickets repo. Aion won't push until you ask it to." (`origin` as a `WidgetSpan` `AionText.key` chip between them)

The swap is a `FadeTransition`, `140ms`, `Curves.easeOut`, and fires on the first character / on clearing — not per keystroke.

Reveal/hide with the checkbox: `AnimatedSize` + `FadeTransition`, `180ms`, `Curves.easeOut` (same curve as the banner's own mount). Unchecking the box keeps the typed URL in the controller so re-checking restores it; the value is only sent to `submit` when `separateTicketsRepo == true`.

### 2.6 Unchecked hint (existing row, dynamic copy)

Shown only when `excludeAionPaths == false`, unchanged in geometry (`Row`, `gap: 7`, left gutter 39, Phosphor `Warning` Light @13 in `AionColors.warning`, caption `AionText.bodySm.copyWith(fontSize: 12, color: textMuted)`, `height: 1.4`). Icon gets `margin: top 1` since the copy can wrap.

- `separateTicketsRepo == false` → `newProjectGitignoreUncheckedHint` (existing, single string, no chip): "Aion's files will be committed to your repo unless you exclude them yourself."
- `separateTicketsRepo == true` → `newProjectGitignoreUncheckedHintAionOnlyBefore` / `...After` (new split, chip between): "The `.aion/` folder will be committed to your repo unless you exclude it yourself."

The card's fill and border still do not change. Notice tone only.

## 3. States

| # | `excludeAionPaths` | `separateTicketsRepo` | `ticketsRepoRemoteUrl` | Visual |
|---|---|---|---|---|
| 1 | true (default) | false (default) | — | Two rows; gitignore label names `.aion/` + `tickets/`; no field, no hint. |
| 2 | true | true | empty | Gitignore label narrows to `.aion/`; field revealed with placeholder; blank helper. |
| 3 | true | true | empty, focused | As 2 with focus border + ring. |
| 4 | true | true | set | Entered URL in `textPrimary`; helper switches to the `origin` line. |
| 5 | false | false | — | Gitignore box empty; hint row, full-files copy. |
| 6 | false | true | empty | Gitignore box empty; field revealed; hint narrowed to `.aion/`. |

All six in both themes in §4 of the mockups. Structure is theme-identical; only token values differ.

Banner height: ~104px today → ~146px at state 1 → ~232px at state 4. At state 1 the form column still fits an ~720px-tall window without scrolling. Once the remote field is revealed the column needs ~780px of window height; below that it scrolls, which is acceptable — but the reveal must not push the Baseline-version field under the action bar, so the form column's `SingleChildScrollView` has to keep the newly revealed field in view: after the reveal animation completes, scroll the banner's bounds into the viewport (`180ms`, `Curves.easeOut`) if the field's bottom edge falls below it.

Keyboard order: gitignore checkbox → tickets-repo checkbox → remote-URL field (skipped when hidden) → Baseline version. Both checkboxes expose `Semantics(button: true, checked: …, label: <label text>)`; the second checkbox's caption is part of its semantic label, not a separate node. The field exposes label + hint via `Semantics(textField: true, label: …, hint: …)`. Icon chip, divider and helper icon stay decorative (`ExcludeSemantics`).

## 4. Rejected alternatives

- **Option B (nested sub-option)** — implies `separateTicketsRepo` requires `excludeAionPaths`; it does not, and it pushes the remote field three levels deep.
- **Option C (segmented "Ticket storage" cards)** — clearest about consequence, but turns a default-off opt-in into a demanded decision on a first-run screen and adds a second control idiom next to a checkbox. Worth revisiting if ticket storage ever gets a third mode.
- **R2 ("Add a remote…" link that expands)** — saves ~70px before the click and nothing after it, at the cost of hiding the field from the user most likely to want it.
- **Remote-URL validation / reachability check** — out of scope; nothing beyond non-empty is implemented, so no error state is designed. If validation lands, it belongs on this field with the existing `AppTextField` error treatment.
- A separate toggle elsewhere on `NewProjectScreen` — rejected per brief; splits one storage decision across two places.

## 5. `app_en.arb`

New keys:

Generated l10n methods return a plain `String` and cannot take a `WidgetSpan` placeholder, so **every new string with an inline path chip is a Before/Middle/After split**, matching `newProjectGitignoreCheckboxLabelBefore`/`...Middle`/`...After` already in the file. Strings with no chip stay single keys.

```json
"newProjectRepoChoicesBody": "Choose how Aion's bookkeeping sits alongside your code. Both choices can be changed later in project settings.",

"newProjectGitignoreCheckboxLabelAionOnlyBefore": "Add ",
"newProjectGitignoreCheckboxLabelAionOnlyAfter": " to .gitignore",

"newProjectSeparateTicketsRepoLabel": "Keep tickets in their own repository",
"newProjectSeparateTicketsRepoHintBefore": "Tickets get a separate Git history in ",
"newProjectSeparateTicketsRepoHintAfter": ", outside your source repo.",

"newProjectTicketsRepoRemoteLabel": "Remote URL",
"newProjectTicketsRepoRemotePlaceholder": "git@github.com:you/aion-tickets.git",
"newProjectTicketsRepoRemoteHintBlank": "Leave blank to keep the repository on this machine only.",
"newProjectTicketsRepoRemoteHintSetBefore": "Set as ",
"newProjectTicketsRepoRemoteHintSetAfter": " on the new tickets repo. Aion won't push until you ask it to.",

"newProjectGitignoreUncheckedHintAionOnlyBefore": "The ",
"newProjectGitignoreUncheckedHintAionOnlyAfter": " folder will be committed to your repo unless you exclude it yourself."
```

Chip values are literals in the widget, not l10n: `.aion/` (label + unchecked hint), `.aion/tickets-repo` (caption), `origin` (helper). `.gitignore` stays inside the `...After` string, as it already does in `newProjectGitignoreCheckboxLabelAfter`.

The "Optional" marker needs **no new key** — `AppTextField(isOptional: true)` uses the existing `commonOptionalMarker`.

Unchanged: `newProjectGitignoreBannerTitle`, `newProjectGitignoreCheckboxLabelBefore`/`...Middle`/`...After`, `newProjectGitignoreUncheckedHint`.

Retired: `newProjectGitignoreBannerBodyBefore` / `...Middle` / `...After` (replaced by the single `newProjectRepoChoicesBody`, which has no chips).

## 6. Wiring

- Banner reads `selectedDirectory`, `directoryIsGitRepo`, `excludeAionPaths`, `separateTicketsRepo`, `ticketsRepoRemoteUrl` from the form controller and writes the two booleans and the string back to it.
- On submit the controller calls `CreateProjectCubit.submit(separateTicketsRepo: …, ticketsRepoRemoteUrl: …)`. The URL is passed only when `separateTicketsRepo == true` and the trimmed value is non-empty; otherwise it is omitted and the repo is created local-only. No new cubit surface.
- **Follow-up fix required, not existing behavior:** `CreateProjectCubit._initializeDesktopProject` currently always passes `['.aion/', 'tickets/']` to the gitignore editor, regardless of `separateTicketsRepo`. For the narrowed `.aion/`-only label in §2.3 to be truthful, that call has to narrow to `['.aion/']` when `separateTicketsRepo == true` — a small AIO-2856 follow-up this task has to land alongside the UI. Shipping the label without it would state something false.
- No repo is created on the remote, and nothing is pushed at create time. The banner's copy commits to that ("Aion won't push until you ask it to"), so any future auto-push needs this copy revisited.
