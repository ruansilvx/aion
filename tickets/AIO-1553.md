# T7. `lib/core/agent/claude_agent_sdk_provider.dart` — ADD:

`ClaudeAgentSdkProvider implements AgentProvider`, constructed with an
`AgentBridgeLocator`, internally building a `ClaudeAgentSdkClient`.
Declares `{ToolAccessTier.noTools, ToolAccessTier.full}` (no
`readOnly`). `availableModels` returns the same three descriptors
`AgentModel`'s enum values used to represent (`claude-opus-4-8`/Opus
4.8, `claude-sonnet-5`/Sonnet 5, `claude-haiku-4-5`/Haiku 4.5, all
`contextWindowTokens: 200000`). `describeOverage` wraps its argument
in `UsageWindowConsumption`. `normalizeErrorMessage` strips
CLI-instruction/vendor-identity text (e.g. `/login`-style slash-command
fragments, "Claude Code" literal mentions) per design.md §2, falling
back to the raw message unchanged when no known pattern matches — see
`provider-error-messages-leak-vendor-text.md`. Depends on T5, T6, and
the existing `claude_agent_sdk_client.dart`/`agent_bridge_locator.dart`
(both untouched). Full dartdoc, file header.
