# 1. `lib/features/tickets/data/daos/ticket_dao.dart` — add

`Future<void> insertTicketPreservingId(TicketsTableCompanion entry)`:
in a single `transaction`, inserts `entry` unchanged (no
sequence-generated `ticketId`), then parses the substring after the
last `-` in `entry.ticketId.value` as an `int`; if it parses and is
greater than the current `TicketIdSequenceTable.seq`, writes it back
via `insertOnConflictUpdate` (same pattern `insertTicket` already
uses). Full dartdoc explaining the id-preservation contract and the
sequence-bump rationale (see `design.md`'s "Sequence-bump logic").
