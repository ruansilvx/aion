# 4. Routing + `ActiveProjectCubit` one-shot offer flag

- [x] 4.1 Modify `aion/lib/features/projects/presentation/cubit/active_project_state.dart` —
      `ActiveProjectOpen` gains `bool offerCodebaseAnalysis` (default
      `false`). Update class dartdoc.
- [x] 4.2 Modify `aion/lib/features/projects/presentation/cubit/active_project_cubit.dart` —
      `switchTo` gains `{bool offerCodebaseAnalysis = false}`, forwarded
      into the emitted `ActiveProjectOpen`. New `consumeCodebaseAnalysisOffer()`
      re-emits the current `ActiveProjectOpen` with the flag cleared
      (no-ops if the current state isn't `ActiveProjectOpen`, or the flag
      is already `false`). Update dartdocs.
- [x] 4.3 Modify `aion/lib/core/routing/app_router.dart` — `NewProjectScreen`'s
      `onCreated` wiring passes `offerCodebaseAnalysis` through;
      `_openProject` gains `{bool offerCodebaseAnalysis = false}`,
      forwarded to `ActiveProjectCubit.switchTo`. Update the function's
      dartdoc.
- [x] 4.4 Extend `test/features/projects/presentation/cubit/active_project_cubit_test.dart`
      — `switchTo(offerCodebaseAnalysis: true)` emits it on
      `ActiveProjectOpen`; `consumeCodebaseAnalysisOffer()` clears it;
      calling it when already `false`, or when not in `ActiveProjectOpen`,
      is a no-op.
