# T1. In `aion/lib/features/tickets/presentation/cubit/tickets_cubit.dart`,

add the private helper `_refreshDetailIfOpenAndAffected(String
writtenTicketId)`: if `state` isn't `TicketDetailLoaded`, return.
If the loaded ticket's `id` equals `writtenTicketId`, `await
getTicketById(...)` for it and return. Otherwise, if the loaded
ticket's `type` is `TicketType.story`, fetch its direct
`task`/`bug` children via `_repository.getTicketsByParent(id,
types: const [TicketType.task, TicketType.bug])` and, if
`writtenTicketId` is among them, `await getTicketById(...)` for the
loaded story. Full dartdoc per `design.md`'s exact code block.
Implemented with one refinement over `design.md`'s literal
snippet: the Story-children query uses
`TicketTypeHierarchy.executableTypes` instead of a hand-written
`const [TicketType.task, TicketType.bug]` literal — that constant's
own dartdoc explicitly says "anywhere a Story's rank-2 children are
gathered for design-review-gate or SDD-readiness purposes should
use this list instead of a `task`-only literal," and `getTicketById`
itself already uses it for the identical query. Same value, more
consistent with existing convention.
