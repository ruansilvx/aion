# Run `flutter analyze` and fix any resulting issues across every

file touched above. Found and fixed two bugs while doing so: a
Material-widget leak (`Divider` in `overrides_list_screen.dart`,
replaced with a plain `DecoratedBox`) and a `widget.project`
scoping mistake in `app_router.dart`'s two new Overrides routes
(they're descendants of `_WorkspaceShellState`'s built tree, not
its own methods — fixed via a new `_activeProject(context)`
helper reading `ActiveProjectCubit` directly, the same source
`WorkspaceShell` itself reads from). Also fixed one **pre-existing,
unrelated** compile error blocking the whole `flutter analyze`
run: `AionShadows.card` passed a nonexistent `inset: true`
argument to `BoxShadow`; removed it (`lib/design_system/tokens/
aion_shadows.dart`, not otherwise touched by this change).
`flutter analyze` now reports no issues.
