# 3. Data Layer — Repository

- [x] **T09** — Create `lib/features/tickets/data/repositories/drift_ticket_repository.dart`
  Implement `DriftTicketRepository implements TicketRepository`.
  Map `TicketData` ↔ `Ticket` (include `ticketId`, `priority`, `estimate`,
  `timeSpent` in both directions). Parse enums by `.name` with safe fallbacks:
  `TicketPriority.none` for unrecognised priority strings.
  `createTicket`: read prefix from `SharedPreferences`
  (key: `ticket_id_prefix`, default `"AIO"`), build `TicketsTableCompanion`,
  call `dao.insertTicket(companion, prefix)`.

- [x] **T09b** — Create `lib/features/tickets/data/repositories/drift_ticket_link_repository.dart`
  Implement `DriftTicketLinkRepository implements TicketLinkRepository`.
  `createLink`: generate UUID, build `TicketLinksTableCompanion`, call
  `dao.insertLink`. `getLinksForTicket`: delegate to `dao.getLinksForTicket`.
  Enum conversion for `link_type` with safe fallback.

- [x] **T09c** — Create `lib/features/tickets/data/repositories/drift_comment_repository.dart`
  Implement `DriftCommentRepository implements CommentRepository`.
  `addComment`: generate UUID if `comment.id` is empty, build
  `TicketCommentsTableCompanion`, call `dao.insertComment`. No UPDATE/DELETE.
  `getCommentsForTicket`: delegate to `dao.getCommentsForTicket`, map to
  `TicketComment` entities. Enum conversion for `author_type`.
