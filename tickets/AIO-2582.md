- [x] **T01** — Create `lib/features/tickets/domain/enums/ticket_type.dart`
  Define `TicketType` enum with values: `epic`, `story`, `task`, `resource`,
  `page`, `chat`.

- [x] **T02** — Create `lib/features/tickets/domain/enums/ticket_status.dart`
  Define `TicketStatus` enum with values: `backlog`, `todo`, `inProgress`,
  `inReview`, `done`, `cancelled`.

- [x] **T02b** — Create `lib/features/tickets/domain/enums/ticket_priority.dart`
  Define `TicketPriority` enum with values: `critical`, `high`, `medium`,
  `low`, `none`. This is the default priority at creation.

- [x] **T02c** — Create `lib/features/tickets/domain/enums/ticket_link_type.dart`
  Define `TicketLinkType` enum with values: `blocks`, `blockedBy`,
  `relatesTo`, `duplicates`, `duplicatedBy`. Serialized as `.name` string.

- [x] **T02d** — Create `lib/features/tickets/domain/enums/comment_author_type.dart`
  Define `CommentAuthorType` enum with values: `human`, `ai`.
  Serialized as `.name` string.

- [x] **T03** — Create `lib/features/tickets/domain/entities/ticket.dart`
  Define `Ticket` Equatable entity with all fields as specified in design.md.
  Fields include: `id` (UUID), `ticketId` (human-readable), `type`, `title`,
  `description`, `status`, `priority` (default `TicketPriority.none`),
  `parentId` (nullable UUID — structural parent/child only), `embedding`
  (nullable Uint8List), `estimate` (int?), `timeSpent` (int?),
  `createdAt`, `updatedAt`. Import `dart:typed_data` for `Uint8List`.

- [x] **T03b** — Create `lib/features/tickets/domain/entities/ticket_comment.dart`
  Define `TicketComment` Equatable entity. Fields: `id` (UUID), `ticketId`
  (FK UUID), `content` (String), `authorType` (CommentAuthorType), `aiModel`
  (String? — set only when `authorType == ai`), `createdAt` (DateTime).
  No `updatedAt` — structural append-only enforcement.

- [x] **T04** — Create `lib/features/tickets/domain/repositories/ticket_repository.dart`
  Define `abstract interface class TicketRepository` with three methods:
  `getAllTickets`, `getTicketById`, `createTicket`.

- [x] **T04b** — Create `lib/features/tickets/domain/repositories/ticket_link_repository.dart`
  Define `abstract interface class TicketLinkRepository` with two methods:
  `getLinksForTicket(String ticketId)` and `createLink({sourceTicketId,
  targetTicketId, linkType})`. No link UI in this slice — domain layer only.

- [x] **T04c** — Create `lib/features/tickets/domain/repositories/comment_repository.dart`
  Define `abstract interface class CommentRepository` with two methods:
  `getCommentsForTicket(String ticketId)` (ordered by `createdAt` ASC) and
  `addComment(TicketComment comment)`. No modify/delete methods.
