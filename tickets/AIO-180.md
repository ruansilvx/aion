# Spec Delta: Automatic Trash Purge on Launch

**Reconciled 2026-09-03:** confirmed against the current `aion-arch/specs/tickets.md` "Trash & bulk delete" section, which states this exact mechanism verbatim: "automatically on every app cold start — `main()` ... fires an unawaited call to `purgeTrashOlderThan(TrashCubit.purgeAgeThreshold)` ... via a private `_purgeOldTrashOnLaunch` helper." No drift — the automated check's low match ratio was a false positive from small sample size plus a qualified-vs-bare identifier mismatch.

Delta against `aion-arch/specs/tickets.md`. On `/archive`, these changes
merge into that file's prose (not appended as a changelog).

## ADDED

### Bootstrap

- `lib/main.dart`: on every app cold start, `main()` fires a fire-and-
  forget call to `TicketRepository.purgeTrashOlderThan(TrashCubit.
  purgeAgeThreshold)` via a new private `_purgeOldTrashOnLaunch` helper,
  immediately after `AppDatabase()` is constructed and without awaiting
  it before `runApp(...)`. This permanently removes every trashed ticket
  older than the existing fixed 30-day threshold, automatically, on
  every launch — no user action required. Failures are swallowed
  silently (no user-facing error surface; see design.md §2, §5).

## MODIFIED

### Known gaps

- The "No automatic/timed purge of Trash" gap in
  `aion-arch/specs/tickets.md`'s Known Gaps section is closed for the
  "user opens the app but never visits the Trash screen" case: purge now
  runs on every launch regardless of which screen is visited. It remains
  open for the narrower "user doesn't open the app at all for an
  extended period" case, since no OS-level background-execution
  mechanism was introduced (see proposal.md's Out of scope) — this
  narrower remainder should be reflected as an updated (not removed)
  Known Gaps bullet at archive time.

## UNCHANGED (confirmed, not modified)

- `TicketRepository.purgeTrashOlderThan`'s cascade semantics, the fixed
  30-day `TrashCubit.purgeAgeThreshold` value, and the manual "Purge
  old"/"Empty trash" actions on the Trash screen — all continue to work
  exactly as documented today, as a manual override alongside the new
  automatic sweep.
