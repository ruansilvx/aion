# Document the convention

- [x] **T4** — Add a "Barrel files" section to
  `aion-arch/flutter-conventions.md` stating: every major `core/`
  grouping and every `features/<feature>/` gets one barrel at its root;
  feature barrels export domain + presentation only, never `data/`;
  design tokens get their own barrel (`design_system.dart`) separate
  from `core.dart`; files inside a directory never import that
  directory's own barrel (self-import exception — only outside
  consumers do); enforced by code review, no lint tooling (same
  precedent as the localization convention).
