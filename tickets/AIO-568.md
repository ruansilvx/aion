# `TicketsCubit` — gate-check migration

      required `WorkflowStatusRepository`/`SddStageConfigRepository`
      parameters; new fields `_workflowStatuses` (`List<WorkflowStatus>`,
      loaded once at construction, refreshed whenever
      `WorkflowConfigCubit` persists a change) and private helpers
      `_resolveStatus(String)`/`_roleOf(String)` (design.md §3). Dartdoc
      both helpers and the refresh mechanism.

      `_interceptTaskExecutionTrigger`, `updateTicketStatus`,
      `updateStatusForTickets`: every `status == TicketStatus.inProgress`
      becomes `_roleOf(status) == WorkflowStatusRole.executionTrigger`
      (design.md §3's table, row 1).

      `updateTicketStatus(task.id, TicketStatus.inReview)` becomes
      resolving the current `reviewReady`-role status's `name` from
      `_workflowStatuses` and writing that string (design.md §3's table,
      row 3).

      branches: `c.status == TicketStatus.done`/`t.status ==
