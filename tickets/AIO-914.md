# 8. In `createTicket`: add

`unawaited(_refreshDetailIfOpenAndAffected({persisted.id}))`
immediately after the existing
`unawaited(_triggerGitProjection(persisted, 'created'))` line —
independent of, and in addition to, the existing
`_estimationSuggester.suggest(persisted).then((_) =>
_refreshDetailIfOpenAndAffected({persisted.id}))` chain (updated
that chain's own call to wrap `persisted.id` in a set literal,
matching the new signature). **Corrected during test-writing**:
the plan above said this new call should read live `state` (no
`fromState`) — wrong. By the time this line runs, `state` has
already been overwritten by this method's own earlier
`emit(TicketCreating(...))`, so a live read can never see a
parent's detail screen that was open when the call started. Fixed
by capturing `stateBeforeThisWrite = state` at the method's very
top (before that emit) and passing `fromState:
stateBeforeThisWrite` to the new call — the *existing*
suggester-chained call correctly keeps reading live `state`
unchanged, since it resolves well after this method's own
emissions complete. Updated the method's dartdoc to explain the
two calls are independent.
