# `design_system/` — additive widget params

- [x] T11. `lib/design_system/atoms/app_text_field.dart` — MODIFY: add
  optional `obscureText` (`bool`, default `false`) and `suffixIcon`
  (`Widget?`, default `null`) params, passed straight through to the
  wrapped `TextField`/`InputDecoration`. No change to any existing call
  site's rendering. Per design.md §9 and its Component Spec §3
  (`ObscuredTextField`) — masking glyph `•`, reveal-toggle icon
  states/hit-target (§3.4), and the new error state using
  `AionColorsHubTokens.errorRing` (not a new inline alpha). Update
  dartdoc.
- [x] T12. `lib/design_system/molecules/app_dropdown.dart` — MODIFY: add
  optional `itemRowLabel` (`String Function(T)?`, default `null`) param
  — used only for the open item panel's label text; falls back to
  `itemLabel` when `null`. Closed-trigger rendering is unchanged
  (always `itemLabel`). No change to any existing call site's
  rendering. Per design.md §8 and its Component Spec §7
  (provider-prefixed dropdown item row) — **note:** Component Spec §7.3
  requires two-tone styling within one row (prefix always `textMuted`
  w500; model name per-state color/weight), which a single-`String`-
  returning `itemRowLabel` cannot express. Widen the param to a
  widget-returning builder (e.g. `Widget Function(T)? itemRowBuilder`,
  rendering a `Text.rich` with two `TextSpan`s per §7.3's table) instead
  of a plain string mapper. Update dartdoc.
