# T18. Fix `CreateTicketScreen`'s type dropdown ordering (finding:

`TicketType.spec` rendered last, after `bug`, instead of
design.md §4.1's "after Page, before Idea," since `create_ticket_screen.dart`
built its `items` list from a bare `TicketType.values.where(...)`
— raw enum-declaration order, and `spec` was appended last in the
enum by T1). Added a new `_dropdownTypes()` helper that keeps
every other type's natural enum position (so a future addition
still appears with no list to maintain) but special-cases `spec`,
inserting it immediately after `TicketType.resource` — the slot
`page` itself occupied before it was excluded from this dropdown.
Verified the resulting order directly against the filtered enum
sequence.
