# Bootstrap

- [x] T1 — `lib/main.dart`: add `import 'dart:async';`. Add a new private
  top-level function `_purgeOldTrashOnLaunch(AppDatabase database)` that
  constructs its own `DriftTicketRepository(database)` and calls
  `purgeTrashOlderThan(TrashCubit.purgeAgeThreshold)` inside a
  `try`/`catch` that swallows any error (no rethrow, no logging — this
  codebase has no logging infrastructure). Full dartdoc per design.md §2
  (state what it does, that it's fire-and-forget, and that failures are
  silently swallowed by design). `TrashCubit` needs no new import — it's
  already exported by the `tickets.dart` barrel `main.dart` already
  imports. Wrap the call in `unawaited` (`dart:async`) so it reads
  unambiguously as deliberate fire-and-forget — not enforced by any
  active lint in this project, just clarity. Per design.md §1–§2.
- [x] T2 — Same file: in `main()`, call
  `unawaited(_purgeOldTrashOnLaunch(database));` immediately after
  `final database = AppDatabase();` and before `runApp(AionApp(database:
  database));`. Update `main()`'s existing dartdoc to mention the purge
  call. Per design.md §2.
