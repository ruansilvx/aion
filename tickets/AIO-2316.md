- [x] T1. Confirm FTS5 actually works against the real bundled WASM
      binary, not just that its symbols are present (see proposal.md's
      "WASM FTS5 support is already confirmed" — that was a static check
      of `aion/web/sqlite3.wasm`, not a live query). Run the app
      (`flutter run -d web-server --web-port 8765` per `.claude/launch.json`,
      real Chrome per `project.md`'s testing convention) and, from a
      throwaway spot in code reachable at startup (e.g. temporarily in
      `AppDatabase`'s constructor or a one-off `customStatement` call),
      execute `CREATE VIRTUAL TABLE fts5_smoketest USING fts5(x);` then
      drop it. Confirm no error. Remove the throwaway code once confirmed
      — this task leaves no trace in the final diff. If this fails,
      **stop** and re-open `/propose` — the whole design depends on it.
