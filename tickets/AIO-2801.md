# Resize the 1024x1024 app icon for linuxdeploy's AppImage size allow-list

Got past libsecret next -- flutter build linux --release and the whole linuxdeploy AppDir staging succeeded, failing only at icon deployment: linuxdeploy validates the icon file's exact pixel dimensions against a fixed list (8x8 up to 512x512) and rejects anything else outright. assets/icons/aion_icon.png is 1024x1024 real Aion artwork (shipped since v1-release-readiness) -- not on that list. Resized to 512x512 (the largest valid size) via ImageMagick's convert before staging, rather than shipping a separate, smaller source icon just for Linux. Added imagemagick to the dependency install list explicitly rather than assuming it's already on the runner image. aion#115. With this, v0.1.0 shipped both Aion-Setup-0.1.0.exe and Aion-0.1.0-x86_64.AppImage.
