# Rewrite `_sddStageAdvanceCheck`'s `exploring`/`verifying`,

`proposed`, `designBrief`, `designSync` branches: build a
`TransitionEvalContext` from the helpers above, call
`evaluateTransitionGraph` against that stage's cached graph,
return `(canAdvance: outcome == allowed, blockReason: outcome ==
blocked ? 'Waiting on: $blockingFieldDisplayName' : null)`. The
`null`/`archived` branches are untouched.
Return type changes to `Future<({bool canAdvance, String?
blockReason})>`.
