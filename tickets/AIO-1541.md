to exercise `_CompactShell`/`_BottomTabBar` live — the web/Chrome pass
in T8 could not do this because `resize_window` had no effect on that
session's browser window. **Verified live** (native `aion.exe`,
resized via Win32 `MoveWindow`, screenshotted via
`System.Drawing.Graphics.CopyFromScreen`, clicked via `mouse_event` —
no browser involved): at 700×900px, the bottom tab bar renders three
cells (Tickets active by default, Documentation, secondary-actions "U"
trigger), no overflow/clipping; tapping Documentation switches the

Project"/"Trash" rows visible and the trigger's menu-open ring showing;
tapping "Switch Project" correctly navigates to `/hub` (previously
entirely unverified — confirmed working); reopening the project and
widening the same live window back to 1400×900 switches back to the
sidebar with no restart needed, and the new T9 brand header (hexagon +
"AION" wordmark) renders correctly at the sidebar's top. Native app and
`flutter run` process stopped at the end of the pass. Resolves
verify-report.md's second WARNING — no bugs found in the previously
untested path this time (unlike T8's sidebar pass, which did surface
