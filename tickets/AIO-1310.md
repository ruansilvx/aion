# 2.2 Modify `aion/lib/features/tickets/presentation/widgets/ticket_overflow_menu.dart` —

`_RootMenu`'s single "Promote to Epic" row becomes two rows
("Promote to Epic" / "Promote to Bug"); `_PromoteChooser` gains a
`targetType` parameter threaded into its `candidatesLoader`
(`all.where((t) => t.type == targetType)` instead of the
hardcoded epic filter) and into its `onCreateNewTap`/
`onLinkSelected` calls to `promoteSignal`. Whichever row matches
`widget.ticket.suggestedType` (when non-null) is visually
distinguished as the suggested default per design.md §7 Widened
"Promote" menu (existing signal chooser, modified) — a
"Suggested" pill (§7.3) plus a resting accent-tinted row
background (§7.3.1), not the draft's own unrelated §7 (Screens &
widgets). The resting-tint alpha pair (0.09/0.06) doesn't match
any existing `AionColorsHubTokens` method (which all close over
one fixed instance field, e.g. `primary`/`danger`) since this one
is parameterized on whichever accent (`typeEpic`/`typeBug`) is
suggested — add a new generic method to that extension taking an
explicit `Color` parameter: `Color accentTint(Color accent, bool
isDark) => accent.withValues(alpha: isDark ? 0.09 : 0.06);` in
`aion/lib/design_system/tokens/aion_colors.dart`. Update widget
dartdocs.
