# Spec Delta: Overlay Menu Item Keyboard Focus

**Reconciled 2026-09-03:** checked against the current `aion-arch/specs/tickets.md's design-system/screens sections` — the mechanism/behavior this delta describes is still present and architecturally coherent with current text. Identifiers the automated screen flagged as missing are private-method requalification, line-wrapped tokens, or names covered in a neighboring section rather than repeated here — not behavioral drift. a small, self-contained accessibility fix (keyboard focus states on overlay menu rows) with no indication of being touched by later, unrelated work.

## ADDED

- **`OverlayMenuItem`** (`design_system/molecules/overlay_menu_item.dart`)
  — a shared, keyboard-focusable/hoverable wrapper for individual rows
  inside an already-open overlay menu: `Semantics(button: true)` →
  a bubbling `Focus` (tracks raw `Enter`/`Space` key-down/key-up so a
  held activation key drives the same pressed feedback as a held
  mouse-down) → `MouseRegion` → `FocusableActionDetector`
  (`ActivateIntent` → the row's own `onTap`) → `GestureDetector`
  (tap/tapDown/tapUp/tapCancel) → a 100ms `Curves.easeOut`
  `AnimatedContainer` fill around the caller-supplied, already-padded
  `child`. Takes `accent` (an optional row accent color, e.g.
  `c.danger` for a destructive row) and `restingTinted` (whether the
  *resting* fill is already tinted with `accent`, e.g. a "Suggested"
  Promote row) instead of a single `restingColor`. Fill: neutral rows
  step `transparent → c.surfaceHover (hover/focus) → c.border
  (pressed)`; accented rows step `transparent or accent @ accentTint
  (resting, per restingTinted) → accent @ fillAlpha (hover/focus) →
  accent @ pressedAccentTint (pressed)` — the last via a new
  `AionColorsHubTokens.pressedAccentTint(accent, isDark)` token (1.6×
  `fillAlpha`). Also takes `autofocus` (claims keyboard focus as soon
  as its menu opens — set on each menu's first row) and `enabled`
  (disabled rows dim to 45% opacity, take no focus stop, and show the
  default cursor). Mirrors `TicketOverflowMenu`'s own trigger button's
  established fill formula, generalized to arbitrary row content. No
  focus ring — hover and keyboard focus render identically, by design
  (see `design.md` §1).

## MODIFIED

- **`TicketOverflowMenu`'s `_MenuActionRow`** (Delete ticket) and
  **`_PromoteRootRow`** (Promote to Epic/Bug) now wrap their content in
  `OverlayMenuItem` instead of a bare `GestureDetector`/`Semantics` —
  both are now Tab-focusable and Enter/Space-activatable, with a
  hover/focus fill previously absent. `_MenuActionRow` passes
  `accent: c.danger`; `_PromoteRootRow` passes `accent:
  c.typeEpic`/`c.typeBug` and `restingTinted: suggested`, preserving
  its existing "suggested" accent-tinted resting background. The first
  row in the opened list (whichever it is — a promote row for
  `signal` tickets, "Delete ticket" otherwise) autofocuses.
- **`TicketOverflowMenu`'s `_PromoteChooser`'s "Create new epic/bug"
  row** — same `OverlayMenuItem` swap, for consistency within the same
  open overlay (its "Link to existing" row and the chooser's back-caret
  button are unchanged — see Explicitly unchanged).
- **`SelectionMenu<T>`'s per-item overlay row** (`selection_menu.dart`)
  now wraps its content (the caller's `itemBuilder` output, or the
  default `Text(itemLabel(item))`) in `OverlayMenuItem`, using
  `itemLabel(item)` as the semantics label — Tab-focusable/activatable,
  first row autofocused. Applies automatically to every existing
  `SelectionMenu<T>` consumer: ticket priority/type/status/complexity
  pickers, the "SDD Stage Automation"/"Coding Execution
  Automation"/"Coding-Execution Retry" pickers
  (`aion-arch/specs/providers.md`), the three model-routing phase
  dropdowns (same file), and the ticket-link-type picker
  (`TicketLinkPicker`'s header `SelectionMenu<TicketLinkType>`).
- **`MoveToStatusMenu`'s per-status overlay row**
  (`tickets_board_view.dart`) now wraps its content in
  `OverlayMenuItem`, using `ticketStatusLabel(context, status)` as the
  semantics label — Tab-focusable/activatable, first row autofocused.
- **`aion-arch/specs/tickets.md`'s Known Gaps section** — the two
  adjacent bullets covering `TicketOverflowMenu`'s "Delete ticket" row
  (no keyboard path) and the overflow menu's dark-theme shadow are both
  removed on `/archive` (see REMOVED below); no replacement bullet is
  added for either, since both are now resolved.
