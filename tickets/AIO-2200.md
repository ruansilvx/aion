# 1. Domain Layer

- [x] **T01** — Modify `lib/features/tickets/domain/entities/ticket.dart`
  Widen `copyWith` to `{title, description, status, priority, type,
  estimate, timeSpent, updatedAt}` per `design.md`. Add the private
  `typedef _FieldSetter<T> = T Function();` and use it for `description`,
  `estimate`, `timeSpent` (nullable, clearable fields); keep `title`,
  `status`, `priority`, `type`, `updatedAt` as plain `?? this.x` params.
  Dartdoc the method explaining the setter-vs-bare-value distinction and
  giving a `() => null` clearing example.
  **Deviation from design.md**: the typedef is public
  (`TicketFieldSetter<T>`), not the private `_FieldSetter<T>` design.md
  and this task's own wording specify — a private type can't appear in
  `copyWith`'s public signature without tripping Dart's
  `library_private_types_in_public_api` lint, since `copyWith` itself is
  public API.

- [x] **T02** — Modify `lib/features/tickets/domain/repositories/ticket_repository.dart`
  Add `Future<void> updateTicket(Ticket ticket)` to the interface per
  `design.md`. Dartdoc: which fields it touches, which it doesn't
  (`status`, `parentId`, `embedding`, `id`, `ticketId`), throws if
  `ticket.id` does not exist.
