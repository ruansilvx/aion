# **T17** — Create `lib/features/tickets/presentation/screens/ticket_detail_screen.dart`

`TicketDetailScreen` StatefulWidget. Exactly per design.md §3.3 and §2.8.
Also defines `CommentTile` in the same file (or adjacent `comment_tile.dart`).
**Setup:**
- Reads `id` from `GoRouterState.pathParameters['id']`.
- `MultiBlocProvider` scoping both `TicketsCubit` and `CommentsCubit` to
this screen only. Inject repositories via `context.read<...Repository>()`.
- `initState`: `cubit.getTicketById(id)` and `commentsCubit.loadComments(id)`.
**Overall layout** (`ColoredBox(color: t.colors.background)` → `Column`):
- **Header** (padding `fromLTRB(20, 6, 20, 12)`):
`AppHeader(showBack: true, onBack: () => context.go('/tickets'), padding: EdgeInsets.fromLTRB(20, 6, 20, 12))`.
Header trailing: `PhosphorIcon(PhosphorIcons.dotsThree, size: 20, color: t.colors.textSecondary)`.
Header title: mono key if ticket loaded (built outside `AppHeader` via
a `BlocBuilder` — pass the loaded `ticketId` as `title` to `AppHeader`
once available, else pass empty string or '…').
- **Body** (`Expanded` → `Stack`):
- `BlocBuilder<TicketsCubit>` + `BlocBuilder<CommentsCubit>` composed in
a `Column` with scroll, minus composer height:
- Scrollable section (`Expanded` → `SingleChildScrollView` → `Column`):
1. **Ticket meta** (`Padding(fromLTRB(20, 16, 20, 16))`):
- If `TicketsLoading`: `Center(AppSpinner())`.
- If `TicketsError`: `Text(error, ...)`.
- If `TicketDetailLoaded`:
- `Semantics(header: true)` wrapping:
- `Row` gap `sp8`: `PriorityBadge(isRow: false)` (omit if none).
- `SizedBox(height: sp8)`.
- `Text(ticket.title, style: AionText.h2.copyWith(color: t.colors.textPrimary))`.
- `SizedBox(height: sp12)`.
- `Row` gap `sp8`: `TypeChip(isRow: false)` + `StatusIndicator`.
- `SizedBox(height: sp16)`.
- If `ticket.description != null`:
- 1px `Container(color: t.colors.border, height: 1)`.
- `SizedBox(height: sp16)`.
- `Text('DESCRIPTION', style: AionText.caption.copyWith(color: t.colors.textMuted))`.
- `SizedBox(height: sp8)`.
- `Text(ticket.description!, style: AionText.body.copyWith(color: t.colors.textSecondary))`.
- `SizedBox(height: sp8)`.
- Timestamps: `Text('Created ${dateStr}', style: AionText.time.copyWith(color: t.colors.textMuted))`.
2. **Comments section**:
- 1px `Container(color: t.colors.border, height: 1)`.
- `Padding(fromLTRB(20, 16, 20, 0))`:
- `BlocBuilder<CommentsCubit>`:
- `CommentsLoading` → `Center(AppSpinner())`.
- `CommentsError` → `Text(error)`.
- `CommentsLoaded` / `CommentAdded` / `CommentAdding`:
- `Text('COMMENTS · ${count}', style: AionText.caption.copyWith(color: t.colors.textMuted))`.
- `SizedBox(height: sp12)`.
- `ListView.builder` (shrinkWrap: true, physics: NeverScrollableScrollPhysics)
of `CommentTile`.
- **Composer** pinned at bottom per §2.10 — outside the scroll area,
at the bottom of the outer `Column`:
- 1px `Container(color: t.colors.border, height: 1)`.
- `ColoredBox(color: t.colors.background)`:
`Padding(fromLTRB(20, 12, 20, 18))` → `Row(crossAxisAlignment: center, gap: sp10)`:
- Human avatar `34×34` circle, fill `t.colors.secondary`,
`Text('U', style: AionText.key.copyWith(color: Color(0xFFFFFFFF)))`. // white initials
- `Expanded` → `DecoratedBox` fill `t.colors.surface`, border 1px
`t.colors.border`, `BorderRadius.all(AionRadius.pill)`:
`Padding(horizontal: 15, vertical: 10)`:
`TextField(controller: _commentController, maxLines: 1,
style: AionText.bodySm.copyWith(color: t.colors.textPrimary, fontSize: 13),
decoration: InputDecoration.collapsed(hintText: 'Add a comment…',
hintStyle: AionText.bodySm.copyWith(color: t.colors.textMuted, fontSize: 13)))`.
Use `InputDecoration.collapsed` here to avoid any border from Material
(border is on the outer `DecoratedBox`).
- Send button `38×38` circle: `GestureDetector(onTap: _sendComment)` →
`DecoratedBox` fill `t.colors.primary`, radius `BorderRadius.circular(19)`,
shadow `AionShadows.fab(t.colors, t.isDark)` (blur 16, use `fab` method):
`Center(PhosphorIcon(PhosphorIcons.paperPlaneTilt, size: 17, color: Color(0xFFFFFFFF)))`. // white glyph
`Semantics(button: true, label: 'Send comment')`.
- `_sendComment()`: if `_commentController.text.trim().isEmpty` return;
else `commentsCubit.addComment(ticketId: id, content: _commentController.text.trim())`;
`_commentController.clear()`.
**CommentTile** (per design.md §2.8 exactly):
- Props: `comment` (TicketComment).
- `Semantics(label: '${comment.authorType.name} comment: ${comment.content}')`.
- `Padding(bottom: AionSpacing.sp16)` → `Row(crossAxisAlignment: start, gap: SizedBox(width: sp10))`:
- Avatar `30×30`:
- AI: square `radius 9`, fill `t.colors.primary` + `boxShadow: AionShadows.aiGlow(t.colors, t.isDark)`:
`PhosphorIcon(PhosphorIcons.sparkle, size: 14, color: Color(0xFFFFFFFF))`. // white glyph
- Human: circle `30×30`, fill `t.colors.secondary`:
`Text('U', style: AionText.prioritySm.copyWith(color: Color(0xFFFFFFFF)))`.
- `Expanded(Column(crossAxisAlignment: start))`:
- **Header row** `Row(crossAxisAlignment: center)`:
- AI: `Text('Aion AI', style: AionText.cardTitle.copyWith(fontSize: 12.5, color: t.colors.primary, fontWeight: FontWeight.w700))`.
+ `SizedBox(width: sp4)` + AI tag: `DecoratedBox` fill `t.colors.primarySubtle`,
radius `BorderRadius.circular(4)`, padding `EdgeInsets.symmetric(horizontal: 6, vertical: 2)`:
`Text('AI', style: AionText.prioritySm.copyWith(color: t.colors.primary))`.
- Human: `Text('You', style: AionText.cardTitle.copyWith(fontSize: 12.5, color: t.colors.textPrimary, fontWeight: FontWeight.w700))`.
- `Spacer()`.
- Timestamp: `Text(timeStr, style: AionText.time.copyWith(color: t.colors.textMuted))`.
- `SizedBox(height: sp4)`.
- **Bubble** `DecoratedBox`:
- `borderRadius: BorderRadius.only(topLeft: Radius.circular(3), topRight: AionRadius.lg, bottomLeft: AionRadius.lg, bottomRight: AionRadius.lg)`.
- AI: fill `t.colors.primarySubtle`, border 1px `t.colors.primary.withOpacity(t.isDark ? 0.42 : 0.28)`.
- Human: fill `t.colors.surface`, border 1px `t.colors.border`.
- `Padding(horizontal: 12, vertical: 10)`:
`Text(comment.content, style: AionText.bodySm.copyWith(color: t.colors.textPrimary, fontSize: 13, height: 1.5))`.
- If AI and `comment.aiModel != null`:
`SizedBox(height: sp4)` + `Text('via ${comment.aiModel}', style: AionText.time.copyWith(color: t.colors.textMuted))`.
All colors via `ThemeScope.of(context)`, spacing via `AionSpacing.*`,
radii via `AionRadius.*`. No raw literals except explicit white glyphs
on colored fills (annotated as `// white on colored fill`).
