reachability live (Tab to focus, Enter/Space to activate). Attempted in
this pass via synthetic `KeyboardEvent('keydown', {key: 'Tab'})`
dispatch in the browser preview — confirmed this does **not** work:
browsers only run native Tab-focus traversal for trusted (real) key
events, not JS-dispatched ones, so the attempt was inconclusive by
construction, not evidence of failure. The fix itself is the same
`FocusableActionDetector`/`ActivateIntent` idiom already proven live in
this session for `TicketBoardCard`'s tap-to-navigate path and used
throughout the rest of the app — needs a real manual Tab/Enter pass
(`flutter run`, physical keyboard) to close out with certainty.
