# Add ticketsRootPath column + schema migration to RegistryDatabase

In lib/core/database/registry_database.dart, add a nullable
`ticketsRootPath` text column (`.named('tickets_root_path')`) to
`ProjectsTable`. Bump `RegistryDatabase.schemaVersion` from `1` to `2`
and add an `onUpgrade` step to the existing `MigrationStrategy`
(currently `onCreate`-only) that adds the new column via
`m.addColumn(projectsTable, projectsTable.ticketsRootPath)` for schema
version 1 -> 2. Additive/backward-compatible: every existing row gets
`NULL` for the new column, no data migration needed.
