# Tasks: Show a last-updated timestamp on each ticket's detail screen

Strict order — each task assumes the previous ones are done. Every task
touching a `.dart` file includes its documentation (dartdoc + file
header, where new) in the same task, per `project.md`'s documentation
rule.

- [x] **T1 — Add the `ticketDetailLastUpdated` l10n key.**
  `aion/lib/l10n/app_en.arb`: add `"ticketDetailLastUpdated": "Updated
  {relative}"` plus its `@ticketDetailLastUpdated` placeholder block
  (`relative`: `String`), immediately after the existing
  `ticketDetailCreatedOn` entry — see design.md §6 for the exact JSON.
  Run `flutter gen-l10n` to regenerate `AppLocalizations` (gitignored
  output, not committed).

- [x] **T2 — Add `TicketsCubit.detailTick` and its lifecycle methods.**
  `aion/lib/features/tickets/presentation/cubit/tickets_cubit.dart`:
  - Add the private `Timer? _detailTickTimer` field and the
    `_detailTickController` broadcast `StreamController<void>` field,
    each with a dartdoc, placed alongside the existing
    `_codebaseAnalysisController` field (see design.md §3 for exact
    text).
  - Add the public `Stream<void> get detailTick` getter, dartdoc'd.
  - Add `void startDetailTicker()` and `void stopDetailTicker()`, both
    dartdoc'd, per design.md §3's exact implementation.
  - Update `close()` to cancel `_detailTickTimer` and close
    `_detailTickController`, alongside the existing
    `_codebaseAnalysisController.close()`/subscription cancels.
  - Ensure `dart:async`'s `Timer` is available (the file already
    imports `dart:async` for `StreamSubscription`/`unawaited` — no new
    import needed).

- [x] **T3 — Add the "Updated" line to `TicketMetadataSection`.**
  `aion/lib/features/tickets/presentation/widgets/ticket_metadata_section.dart`:
  directly below the existing `Text(context.l10n.ticketDetailCreatedOn(
  ...))` (the section's last child before the closing divider), add
  the `SizedBox(height: AionSpacing.sp4)` + `StreamBuilder<void>(
  stream: context.read<TicketsCubit>().detailTick, ...)` block exactly
  as specified in design.md §4, rendering
  `context.l10n.ticketDetailLastUpdated(formatRelativeTime(
  ticket.updatedAt))` styled with `AionText.time.copyWith(color:
  c.textMuted)`. `formatRelativeTime` comes from `core/core.dart`
  (already imported in this file as `package:aion/core/core.dart`) —
  no new import needed. Update this class's existing doc comment to
  mention the new "Updated" line alongside its existing mention of the
  "created-on timestamp."

- [x] **T4 — Wire the ticker into `TicketDetailScreen`'s lifecycle.**
  `aion/lib/features/tickets/presentation/screens/ticket_detail_screen.dart`:
  - `initState`: add
    `context.read<TicketsCubit>().startDetailTicker();` alongside the
    existing `getTicketById`/`loadComments`/`loadMessages` calls (see
    design.md §5 for exact placement).
  - `dispose`: add `context.read<TicketsCubit>().stopDetailTicker();`
    before `_commentController.dispose()`, mirroring the existing
    `ActiveTicketViewRegistry` unregister block immediately above it.
  - No new imports needed (`TicketsCubit` is already imported here).

- [x] **T5 — Fix `ticket_metadata_section_test.dart`'s `MockTicketsCubit`
  stub so existing tests keep passing.**
  `aion/test/features/tickets/presentation/widgets/ticket_metadata_section_test.dart`:
  in the `_wrap` helper, add
  `when(() => ticketsCubit.detailTick).thenAnswer((_) =>
  const Stream<void>.empty());` before (or alongside) the existing
  `whenListen(ticketsCubit, ...)` call. Required because `T3` makes
  `TicketMetadataSection` call `.detailTick` unconditionally on every
  build, and `MockTicketsCubit` (a `mocktail` `Mock`) throws on any
  unstubbed call — every existing test in this file renders
  `TicketMetadataSection` through `_wrap`, so without this fix the
  entire file fails after T3, not just a new test case.

- [x] **T6 — Add a widget-test case for the "Updated" line.**
  Same file as T5 (`ticket_metadata_section_test.dart`): add a test
  asserting `context.l10n.ticketDetailLastUpdated(formatRelativeTime(
  ticket.updatedAt))`'s exact rendered text is found via
  `find.text(...)`, using a ticket fixture with a fixed `updatedAt`
  (e.g. `DateTime.now().subtract(const Duration(minutes: 5))`) and
  matching the assertion against `formatRelativeTime` computed the same
  way (tolerant of the small real-clock skew between fixture
  construction and assertion, same caveat every other "now"-based
  render test in this codebase already accepts — no `now:` override
  exists on the widget side to eliminate it).

- [x] **T7 — Add `bloc_test` coverage for the ticker lifecycle.**
  `aion/test/features/tickets/presentation/cubit/tickets_cubit_test.dart`:
  add a `group('detailTick', ...)` with two cases: (1)
  `stopDetailTicker()` called with no prior `startDetailTicker()` does
  not throw, and (2) calling `startDetailTicker()` twice in a row does
  not throw and the second call's internal `_detailTickTimer?.cancel()`
  correctly replaces the first timer (assert via public contract only
  — this cubit's `Timer` field is private, so these are "doesn't
  throw / doesn't leak an exception" contract tests, not internal state
  inspection). See design.md §3 for why full elapsed-time tick
  verification is left to the widget-level test instead.

- [x] **T8 — Add unit-test coverage for `formatRelativeTime`.**
  `aion/test/core/utils/relative_time_format_test.dart`: add a new
  `group('formatRelativeTime', ...)` alongside the existing
  `formatTrashedAge` group (same file, same `now`-parameter pattern),
  covering every bucket: `< 60s` → `'just now'`, `1m`/`59m` → `'{n}m
  ago'`, `1h`/`23h` → `'{n}h ago'`, `1d`/`6d` → `'{n}d ago'`,
  `7d`/`29d` → `'{n}w ago'`, `30d`+ → `'{n}mo ago'`, plus the `now`
  defaulting-to-`DateTime.now()` case. See design.md §7/spec.md's
  ADDED section for why this pre-existing gap is closed as part of
  this change.
