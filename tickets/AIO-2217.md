Inside the `TicketDetailLoaded(:final ticket) =>` branch:
- Replace `PriorityBadge(priority: ticket.priority, isRow: false)` with
`SelectionMenu<TicketPriority>(trigger: PriorityBadge(priority:
ticket.priority, isRow: false), items: TicketPriority.values,
itemLabel: (p) => p.name, currentValue: ticket.priority, onSelected:
(p) => context.read<TicketsCubit>().updateTicket(ticket.copyWith(priority: p)),
semanticsLabel: 'Change priority')`.
- Replace `Text(ticket.title, style: AionText.h2...)` with
`InlineEditableField<String>(displayText: ticket.title, editText:
ticket.title, maxLines: 1, semanticsLabel: 'Edit title', parser: (raw) {
final t = raw.trim(); if (t.isEmpty) { throw const FormatException('Title is required'); } return t; },
onCommit: (v) => context.read<TicketsCubit>().updateTicket(ticket.copyWith(title: v)))`.
- Replace `TypeChip(type: ticket.type, isRow: false)` with
`SelectionMenu<TicketType>(trigger: TypeChip(type: ticket.type,
isRow: false), items: TicketType.values, itemLabel: (t) => t.name,
currentValue: ticket.type, onSelected: (t) =>
context.read<TicketsCubit>().updateTicket(ticket.copyWith(type: t)),
semanticsLabel: 'Change type')`.
- Leave `StatusIndicator(status: ticket.status)` untouched.
- Replace the `if (ticket.description != null) ...` conditional block
with an always-rendered `InlineEditableField<String?>(displayText:
ticket.description ?? '', editText: ticket.description ?? '',
maxLines: 6, placeholder: 'Add a description…', semanticsLabel: 'Edit
description', parser: (raw) { final t = raw.trim(); return t.isEmpty
? null : t; }, onCommit: (v) =>
context.read<TicketsCubit>().updateTicket(ticket.copyWith(description: () => v)))`.
- Add a new meta row between the type/status row and the description
block: two `InlineEditableField<int?>` instances for Estimate and
Time Spent, each with a small caption label (`AionText.caption` /
`c.textMuted`, matching the existing 'DESCRIPTION' header style):
- Estimate: `displayText`/`editText` from
`formatDurationMinutes(ticket.estimate, placeholder: '')`,
`placeholder: 'Add an estimate…'`, `parser: parseDurationMinutes`,
`onCommit: (v) => context.read<TicketsCubit>().updateTicket(ticket.copyWith(estimate: () => v))`.
- Time spent: same shape, using `ticket.timeSpent` /
`ticket.copyWith(timeSpent: () => v)`.
- Import `inline_editable_field.dart` and `selection_menu.dart`.
- Exact spacing/visual polish of the new meta row is finalized via the
Design gate (`/design-brief` → Claude Design → `/opsx-design-sync`)
