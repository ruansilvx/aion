# **T7 — Add `bloc_test` coverage for the ticker lifecycle.**

`aion/test/features/tickets/presentation/cubit/tickets_cubit_test.dart`:
add a `group('detailTick', ...)` with two cases: (1)
`stopDetailTicker()` called with no prior `startDetailTicker()` does
not throw, and (2) calling `startDetailTicker()` twice in a row does
not throw and the second call's internal `_detailTickTimer?.cancel()`
correctly replaces the first timer (assert via public contract only
— this cubit's `Timer` field is private, so these are "doesn't
throw / doesn't leak an exception" contract tests, not internal state
inspection). See design.md §3 for why full elapsed-time tick
verification is left to the widget-level test instead.
