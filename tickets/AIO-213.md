# `lib/features/providers/presentation/widgets/decision_node_form.dart`

— `DecisionNodeForm`: condition picker (`SelectionMenu` over
`decisionConditionsFor(context)`), typed parameter fields per
`DecisionConditionSpec.parameterSpecs`, matched/unmatched branch
picker (terminal outcome `SelectionMenu` or "continue to another
condition"). Shared by both panes. Per design.md §3
`DecisionNodeForm` (§3.1–§3.5: condition picker, parameter field,
matched-branch picker, unmatched-branch picker, actions) —
implement both the inline mount and the popover mount described
there. Fixed in the `/verify` follow-up pass: added the
`DecisionBranchMode`-driven two-segment "End here / Continue to
condition" control per branch (`_BranchSection`/
`_BranchModeToggle`); picking "Continue to condition" for a
not-yet-chained branch creates the child node via the new
`onCreateChainedChild` callback (bound by each mount to
`DecisionGraphConfigCubit.createNode`) and attaches it as that
branch's `DecisionBranch.toNode` target — an already-chained branch
shows its child's condition name read-only (editing that child
happens on its own row/canvas node instead).
