# 2. Create `design_system/atoms/`

For each file: update header comment to the new path/layer, replace
the blanket `import 'package:aion/core/design_system.dart';` with
direct imports of only the `../tokens/*.dart` files the file actually
uses (see design.md's per-file table — verify against real usage, the
table is a starting point), and replace any
`import 'package:aion/core/localization/context_localizations_x.dart';`
with `import 'package:aion/core/core.dart';` (see design.md "Crossing
out of `design_system/` into `core/`").

- [x] Create `lib/design_system/atoms/app_button.dart` from
      `lib/core/widgets/app_button.dart`. Tokens needed: `aion_colors`,
      `aion_radius`, `aion_text`, `theme_scope`. Matched the table exactly.
- [x] Create `lib/design_system/atoms/app_checkbox.dart` from
      `lib/core/widgets/app_checkbox.dart`. Tokens needed: `aion_radius`,
      `theme_scope`. Matched the table exactly; also updated its dartdoc's
      stale `core/widgets/` self-reference to `design_system/atoms/`.
- [x] Create `lib/design_system/atoms/app_text_field.dart` from
      `lib/core/widgets/app_text_field.dart`. Tokens actually used in code:
      `aion_radius`, `aion_shadows`, `aion_text`, `theme_scope` — `AionColors`
      appears only inside a `///` doc-comment bracket reference, never as a
      real symbol, so importing `aion_colors.dart` would be an unused
      import; left out to keep `flutter analyze` clean. Kept its
      `context_localizations_x.dart` import → `core/core.dart`.
- [x] Create `lib/design_system/atoms/app_spinner.dart` from
      `lib/core/widgets/app_spinner.dart`. Tokens needed: `theme_scope`.
      Kept its `context_localizations_x.dart` import → `core/core.dart`.
