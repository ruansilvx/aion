# 6. Presentation — Screens

- [x] **T15** — Create `lib/features/tickets/presentation/screens/tickets_list_screen.dart`
  `TicketsListScreen` StatefulWidget. Layout exactly per design.md §3.1.
  Also defines `TicketListTile`, `PriorityBadge`, `TypeChip`, `AppFab` in
  the same file (or separate files in the same `screens/` directory — keep
  simple, move later if library grows). Rules:

  **TicketsListScreen layout (`ColoredBox(color: t.colors.background)`):**
  - No `Scaffold`, no `AppBar`. Root is `Stack` (body + FAB overlay).
  - Header block (not `AppHeader` — list screen uses its own header layout):
    - `Padding(EdgeInsets.fromLTRB(20, 8, 20, 0))`:
      - Eyebrow: `Text('AION · MAIN', style: AionText.caption.copyWith(color: t.colors.textMuted))`.
      - `SizedBox(height: AionSpacing.sp4)`.
      - `Row` — `Expanded(Text('Tickets', style: AionText.h1.copyWith(color: t.colors.textPrimary)))`
        + outlined avatar `38×38` (fill `t.colors.surfaceHover`, border 1px
        `t.colors.border`, full circle, initials `AionText.key` `t.colors.textSecondary`).
    - `SizedBox(height: AionSpacing.sp12)`.
    - Search bar: `Padding(horizontal: 20)` → `DecoratedBox` fill `t.colors.surface`,
      border 1px `t.colors.border`, radius `AionRadius.lg`:
      - `Padding(EdgeInsets.symmetric(horizontal: 13, vertical: 11))` → `Row`:
        `PhosphorIcon(PhosphorIcons.magnifyingGlass, size: 16, color: t.colors.textMuted)`,
        `SizedBox(width: AionSpacing.sp8)`,
        `Text('Search tickets', style: AionText.bodySm.copyWith(color: t.colors.textMuted))`.
    - `SizedBox(height: AionSpacing.sp4)`.
  - List body: `Expanded` → `ColoredBox(color: t.colors.surface)` + top 1px
    `border` → `BlocBuilder<TicketsCubit, TicketsState>`:
    - `TicketsLoading` → `Center(AppSpinner())`.
    - `TicketsError` → `Center(Column([Text(error), AppButton(label: 'Retry', ...)]))`
    - `TicketsLoaded` with empty list → `Center(Text('No tickets yet', style: AionText.body.copyWith(color: t.colors.textMuted)))`.
    - `TicketsLoaded` → `ListView.separated` of `TicketListTile`,
      `separatorBuilder`: 1px `Container(color: t.colors.border, height: 1)`.
  - FAB: `Positioned(right: 18, bottom: 24)` → `AppFab`.
  - Calls `cubit.loadTickets()` in `initState`.

  **AppFab** (defined here or in `lib/core/widgets/app_fab.dart`):
  - Extended pill per design.md §2.9.
  - `GestureDetector(onTap: onTap)` → `DecoratedBox` fill `t.colors.primary`,
    radius `BorderRadius.all(AionRadius.xl)`, shadow `AionShadows.fab(t.colors, t.isDark)`.
  - Padding: `EdgeInsets.symmetric(horizontal: 18, vertical: 14)`.
  - Content `Row(gap: AionSpacing.sp8)`:
    - `Text('+', style: TextStyle(fontSize: 18, color: Color(0xFFFFFFFF), fontWeight: FontWeight.w700))` // white on primary
    - `Text('New ticket', style: AionText.button.copyWith(color: Color(0xFFFFFFFF)))`.
  - `Semantics(button: true, label: 'Create ticket')`.

  **TicketListTile** (per design.md §2.7 exactly):
  - `Semantics(label: '${ticket.ticketId} ${ticket.title}', button: true)` wrapping.
  - `FocusableActionDetector` for keyboard Enter/Space activation.
  - `GestureDetector(onTap: () => context.go('/tickets/${ticket.id}'))`.
  - Visual: `ColoredBox(color: t.colors.surface)`, padding
    `EdgeInsets.symmetric(horizontal: 20, vertical: 12)`.
  - `Column(crossAxisAlignment: start, gap gap via SizedBox(height: AionSpacing.sp8))`:
    - **Top row** `Row(gap via SizedBox(width: AionSpacing.sp12))`:
      - ID badge: `DecoratedBox` fill `t.colors.surfaceHover`, radius
        `BorderRadius.circular(5)`, padding `EdgeInsets.symmetric(horizontal: 6, vertical: 2)`:
        `Text(ticket.ticketId, style: AionText.key.copyWith(color: t.colors.textSecondary, fontSize: 10.5))`.
      - `Expanded(Text(ticket.title, style: AionText.cardTitle.copyWith(color: t.colors.textPrimary), maxLines: 1, overflow: TextOverflow.ellipsis))`.
      - If `ticket.priority != TicketPriority.none`: `PriorityBadge(priority: ticket.priority)`.
    - **Meta row** `Row(gap via SizedBox(width: AionSpacing.sp12))`:
      - `TypeChip(type: ticket.type, isRow: true)`.
      - `StatusIndicator(status: ticket.status)`.

  **PriorityBadge** (per design.md §2.3):
  - Props: `priority` (TicketPriority), `isRow` (bool, default true).
  - Omit entirely (return `SizedBox.shrink()`) when `priority == TicketPriority.none`.
  - `DecoratedBox` fill `t.colors.priority.{level}Bg`, radius `BorderRadius.circular(5)`.
  - Padding `EdgeInsets.symmetric(horizontal: 7, vertical: 3)` (row) or
    `(horizontal: 11, vertical: 5)` (detail).
  - Text: UPPERCASE priority name, style `AionText.prioritySm` (row) or
    `AionText.priorityBig` (detail), color `t.colors.priority.{level}Fg`.

  **TypeChip** (per design.md §2.2):
  - Props: `type` (TicketType), `isRow` (bool, default true).
  - Padding `EdgeInsets.fromLTRB(5, 2, 7, 2)` (row) or `(6, 3, 8, 3)` (detail).
  - `DecoratedBox` fill `typeColor.withOpacity(t.fillAlpha)`, radius `BorderRadius.circular(5)`.
  - `Row(gap: SizedBox(width: 5))`:
    - Leading square: `9×9` (row) or `11×11` (detail), `DecoratedBox` fill
      `typeColor`, radius `BorderRadius.circular(2)`.
    - `Text(ticket.type.name.toUpperCase(), style: AionText.chip.copyWith(color: typeColor))`.
  - `typeColor`: `t.colors.typeTask` / `t.colors.typeStory` / `t.colors.typeEpic`.

  **StatusIndicator** (per design.md §2.4):
  - `Row(gap: SizedBox(width: 7))`:
    - Dot `7×7` circle, `DecoratedBox` rounded: backlog → `t.colors.textMuted`,
      inProgress → `t.colors.primary`, done → `t.colors.success`, others → `t.colors.textMuted`.
    - `Text(statusLabel, style: AionText.label.copyWith(color: t.colors.textSecondary, fontWeight: FontWeight.w600, fontSize: 12))`.

  All colors via `ThemeScope.of(context)`, all spacing via `AionSpacing.*`,
  all radii via `AionRadius.*`. No raw literals.

- [x] **T16** — Create `lib/features/tickets/presentation/screens/create_ticket_screen.dart`
  `CreateTicketScreen` StatefulWidget. Exactly per design.md §3.2. Rules:
  - Root: `ColoredBox(color: t.colors.background)` → `Column`.
  - **Header**: `AppHeader(title: 'New ticket', showBack: true, onBack: () => context.go('/tickets'), padding: EdgeInsets.fromLTRB(20, 6, 20, 16))`.
  - **Body**: `Expanded` → `SingleChildScrollView` → `Padding(EdgeInsets.fromLTRB(20, 6, 20, 0))`:
    - `Column(crossAxisAlignment: start, children:` with `SizedBox(height: AionSpacing.sp20)` gaps between:
      1. `AppTextField(labelText: 'Title', isRequired: true, hintText: 'Ticket title', controller: _titleController, focusNode: _titleFocus, textInputAction: TextInputAction.next, onSubmitted: (_) => _typeFocus.requestFocus())`.
      2. `AppDropdown<TicketType>(labelText: 'Type', value: _selectedType, items: TicketType.values, onChanged: (v) => setState(() => _selectedType = v), itemLabel: (t) => t.name, focusNode: _typeFocus)`.
      3. `AppDropdown<TicketPriority>(labelText: 'Priority', value: _selectedPriority, items: TicketPriority.values, onChanged: (v) => setState(() => _selectedPriority = v), itemLabel: (p) => p.name, focusNode: _priorityFocus)`.
      4. `AppTextField(labelText: 'Description', isOptional: true, hintText: 'Add details…', controller: _descController, focusNode: _descFocus, maxLines: 6, textInputAction: TextInputAction.done)`.
  - **Footer**: `Padding(EdgeInsets.fromLTRB(20, 14, 20, 24))`:
    - `AppButton(label: 'Create ticket', variant: AppButtonVariant.primary, isFullWidth: true, onPressed: _isSubmitting ? null : _submit)`.
  - FocusNode order: `_titleFocus` → `_typeFocus` → `_priorityFocus` → `_descFocus` → submit.
    Use `FocusScope.of(context).nextFocus()` on `TextInputAction.next`.
  - `_submit()`:
    ```dart
    setState(() => _isSubmitting = true);
    context.read<TicketsCubit>().createTicket(
      type: _selectedType, title: _titleController.text.trim(),
      description: _descController.text.trim().isEmpty ? null : _descController.text.trim(),
      priority: _selectedPriority,
    );
    ```
  - `BlocListener<TicketsCubit, TicketsState>`:
    - `TicketCreated` → `context.go('/tickets')`.
    - `TicketsError` → `AppToast.show(context, state.message)`; `setState(() => _isSubmitting = false)`.
  - All colors via `ThemeScope.of(context)`, spacing via `AionSpacing.*`,
    radii via `AionRadius.*`. No raw literals.

- [x] **T17** — Create `lib/features/tickets/presentation/screens/ticket_detail_screen.dart`
  `TicketDetailScreen` StatefulWidget. Exactly per design.md §3.3 and §2.8.
  Also defines `CommentTile` in the same file (or adjacent `comment_tile.dart`).

  **Setup:**
  - Reads `id` from `GoRouterState.pathParameters['id']`.
  - `MultiBlocProvider` scoping both `TicketsCubit` and `CommentsCubit` to
    this screen only. Inject repositories via `context.read<...Repository>()`.
  - `initState`: `cubit.getTicketById(id)` and `commentsCubit.loadComments(id)`.

  **Overall layout** (`ColoredBox(color: t.colors.background)` → `Column`):
  - **Header** (padding `fromLTRB(20, 6, 20, 12)`):
    `AppHeader(showBack: true, onBack: () => context.go('/tickets'), padding: EdgeInsets.fromLTRB(20, 6, 20, 12))`.
    Header trailing: `PhosphorIcon(PhosphorIcons.dotsThree, size: 20, color: t.colors.textSecondary)`.
    Header title: mono key if ticket loaded (built outside `AppHeader` via
    a `BlocBuilder` — pass the loaded `ticketId` as `title` to `AppHeader`
    once available, else pass empty string or '…').
  - **Body** (`Expanded` → `Stack`):
    - `BlocBuilder<TicketsCubit>` + `BlocBuilder<CommentsCubit>` composed in
      a `Column` with scroll, minus composer height:
    - Scrollable section (`Expanded` → `SingleChildScrollView` → `Column`):
      1. **Ticket meta** (`Padding(fromLTRB(20, 16, 20, 16))`):
         - If `TicketsLoading`: `Center(AppSpinner())`.
         - If `TicketsError`: `Text(error, ...)`.
         - If `TicketDetailLoaded`:
           - `Semantics(header: true)` wrapping:
             - `Row` gap `sp8`: `PriorityBadge(isRow: false)` (omit if none).
             - `SizedBox(height: sp8)`.
             - `Text(ticket.title, style: AionText.h2.copyWith(color: t.colors.textPrimary))`.
           - `SizedBox(height: sp12)`.
           - `Row` gap `sp8`: `TypeChip(isRow: false)` + `StatusIndicator`.
           - `SizedBox(height: sp16)`.
           - If `ticket.description != null`:
             - 1px `Container(color: t.colors.border, height: 1)`.
             - `SizedBox(height: sp16)`.
             - `Text('DESCRIPTION', style: AionText.caption.copyWith(color: t.colors.textMuted))`.
             - `SizedBox(height: sp8)`.
             - `Text(ticket.description!, style: AionText.body.copyWith(color: t.colors.textSecondary))`.
           - `SizedBox(height: sp8)`.
           - Timestamps: `Text('Created ${dateStr}', style: AionText.time.copyWith(color: t.colors.textMuted))`.
      2. **Comments section**:
         - 1px `Container(color: t.colors.border, height: 1)`.
         - `Padding(fromLTRB(20, 16, 20, 0))`:
           - `BlocBuilder<CommentsCubit>`:
             - `CommentsLoading` → `Center(AppSpinner())`.
             - `CommentsError` → `Text(error)`.
             - `CommentsLoaded` / `CommentAdded` / `CommentAdding`:
               - `Text('COMMENTS · ${count}', style: AionText.caption.copyWith(color: t.colors.textMuted))`.
               - `SizedBox(height: sp12)`.
               - `ListView.builder` (shrinkWrap: true, physics: NeverScrollableScrollPhysics)
                 of `CommentTile`.
    - **Composer** pinned at bottom per §2.10 — outside the scroll area,
      at the bottom of the outer `Column`:
      - 1px `Container(color: t.colors.border, height: 1)`.
      - `ColoredBox(color: t.colors.background)`:
        `Padding(fromLTRB(20, 12, 20, 18))` → `Row(crossAxisAlignment: center, gap: sp10)`:
        - Human avatar `34×34` circle, fill `t.colors.secondary`,
          `Text('U', style: AionText.key.copyWith(color: Color(0xFFFFFFFF)))`. // white initials
        - `Expanded` → `DecoratedBox` fill `t.colors.surface`, border 1px
          `t.colors.border`, `BorderRadius.all(AionRadius.pill)`:
          `Padding(horizontal: 15, vertical: 10)`:
          `TextField(controller: _commentController, maxLines: 1,
           style: AionText.bodySm.copyWith(color: t.colors.textPrimary, fontSize: 13),
           decoration: InputDecoration.collapsed(hintText: 'Add a comment…',
           hintStyle: AionText.bodySm.copyWith(color: t.colors.textMuted, fontSize: 13)))`.
          Use `InputDecoration.collapsed` here to avoid any border from Material
          (border is on the outer `DecoratedBox`).
        - Send button `38×38` circle: `GestureDetector(onTap: _sendComment)` →
          `DecoratedBox` fill `t.colors.primary`, radius `BorderRadius.circular(19)`,
          shadow `AionShadows.fab(t.colors, t.isDark)` (blur 16, use `fab` method):
          `Center(PhosphorIcon(PhosphorIcons.paperPlaneTilt, size: 17, color: Color(0xFFFFFFFF)))`. // white glyph
          `Semantics(button: true, label: 'Send comment')`.
      - `_sendComment()`: if `_commentController.text.trim().isEmpty` return;
        else `commentsCubit.addComment(ticketId: id, content: _commentController.text.trim())`;
        `_commentController.clear()`.

  - Props: `comment` (TicketComment).
  - `Semantics(label: '${comment.authorType.name} comment: ${comment.content}')`.
  - `Padding(bottom: AionSpacing.sp16)` → `Row(crossAxisAlignment: start, gap: SizedBox(width: sp10))`:

        `Text('U', style: AionText.prioritySm.copyWith(color: Color(0xFFFFFFFF)))`.
    - `Expanded(Column(crossAxisAlignment: start))`:
      - **Header row** `Row(crossAxisAlignment: center)`:

          radius `BorderRadius.circular(4)`, padding `EdgeInsets.symmetric(horizontal: 6, vertical: 2)`:
