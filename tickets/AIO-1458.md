# T46a. **(added by /design-sync)** Create

`lib/features/tickets/presentation/widgets/resume_runs_prompt.dart` —
`ResumeRunsPrompt`, a one-time-per-launch inline banner pinned to the
top of the Board view, listing interrupted coding-execution runs with
Resume/Dismiss actions, per the Claude Design export's design.md §3.
Shown only when `restoreExecutionQueue()` (T36)'s `gated` branch has
surfaced pending entries to resume — this likely needs a small
`TicketsState` addition (e.g. a `pendingResumePrompt` field on
`TicketsLoaded`) to carry those entries from `restoreExecutionQueue()`
to the Board widget; exact shape left for `/apply` to size against
T36's actual implementation. Resume re-enqueues every surviving entry
and calls `_tryStartNextQueuedExecutions()` (same as T36's `auto`
path); Dismiss falls back to `manual`'s behavior (clear the snapshot,
rely on the existing orphaned/stalled retry banner). File header +
dartdoc.
