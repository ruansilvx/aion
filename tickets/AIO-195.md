# `TicketsCubit` wiring (`lib/features/tickets/presentation/cubit/tickets_cubit.dart`)

- [x] Add optional constructor parameter `DecisionGraphRepository?
      decisionGraphRepository`; cached `Map<AutomationContext,
      DecisionGraph>`/`Map<String, DecisionNode>` state, loaded once at
      construction and refreshed on `DecisionGraphRepository.onChanged`
      — mirrors `_workflowStatuses`'s own cache-and-refresh pattern.
- [x] Add private helper `_evaluateDecisionGraph(AutomationContext,
      DecisionEvalContext)` (see `design.md` §4) — returns `proceed`
      when constructed without a repository or when the context's graph
      has a `null` root.
- [x] Extend `_handleCreateTicketToolCall`'s `case
      AutomationConfidence.auto:` to consult
      `_evaluateDecisionGraph(AutomationContext.ticketCreation, ...)`
      before calling `create()`; route `.gated` through the existing
      `_awaitProposalConfirmation` path, `.decline` through the existing
      decline-reason shape.
- [x] Same extension for `_handleAddLinkToolCall`
      (`AutomationContext.ticketLinking`).
- [x] Same extension for `_handleBranchToolCall`/
      `_handleCloseBranchToolCall` (`AutomationContext.chatBranching`)
      — **after** the existing `_canBranch` depth-cap pre-check, which
      stays unconditional and untouched.
- [x] Same extension for the `codingExecution` completion-flip path and
      the `codingExecutionRetry` retry-feedback path.
- [x] Same extension for `_maybeAutoLinkToSpec`
      (`AutomationContext.specAutoLink`).
- [x] Same extension for `restoreExecutionQueue`'s `case
      AutomationConfidence.auto:` (`AutomationContext.codingExecutionResume`,
      `tickets_cubit.dart:4430`) — fixed in the `/verify` follow-up pass;
      `.gated` routes through the existing `_pendingResumeTickets` surface,
      `.decline` clears the persisted snapshot (the same treatment
      `.manual` gets), `.proceed`/`.modelJudgment` resume exactly as
      `auto` always has.
- [x] `_effectiveCodingExecutionRetryConfidence` — remove the
      `attempt > _maxVerifyRetries` hardcoded override; becomes a plain
      `getConfidence(AutomationContext.codingExecutionRetry)`
      passthrough.
- [x] `_effectiveCodingExecutionConfidence` — remove the
      `_overageDetectedThisSession` hardcoded override; becomes a plain
      `getConfidence(AutomationContext.codingExecution)` passthrough.
- [x] `TicketDetailScreen`'s direct `getConfidence(AutomationContext.sddStage)`
      read (`ticket_detail_screen.dart:177`) — extend with the same
      graph-consultation step (baseline `null` root, so no behavior
      change until a project edits this graph).
- [x] Update every existing construction site that supplies
      `WorkflowStatusRepository` (tests included) to also decide whether
      it needs `decisionGraphRepository` — most don't, since omitting it
      exactly reproduces pre-change behavior.
