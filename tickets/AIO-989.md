# **T21** — Modify the shared Markdown AST-to-widgets renderer

(`MarkdownView` — confirm exact file, likely `design_system/molecules/
markdown_view.dart` or `design_system/atoms/`): add optional `Ticket?
Function(String target)? resolveWikilink`, `void Function(Ticket)?
onWikilinkTap`, and `void Function(String title)?
onCreateWikilinkTarget` parameters. Parse `[[Target]]`/
`[[Target|Alias]]` sequences via `WikilinkExtractor.extractReferences`
(reused directly, not a second ad hoc regex — `core/markdown/` has no
Flutter dependency). For each match: if `resolveWikilink(match.target)`
is non-`null`, render a tappable, visually distinct resolved span
(calls `onWikilinkTap`) whose displayed text is `match.alias` when
present, otherwise the resolved `Ticket.title` live; if `null`, render
a plain, chip-backed unresolved span, tappable-to-create only when
`onCreateWikilinkTarget != null` **and**
`!WikilinkExtractor.looksLikeTicketId(match.target)` (an unresolved
id means the target was trashed/deleted, not a new-page candidate).
All three parameters default to `null`, preserving every other
consumer's current behavior unchanged. Update dartdoc. Per design.md
§5 (Inline wikilink span — resolved & tappable: §5.1 rendered text,
§5.2 states) and §6 (Inline wikilink span — unresolved: §6.1 rendered
text, §6.2 states, §6.3 contrast rationale).
