# 4. Data layer — `features/projects/data/`

- [x] 4.1 `data/models/project_model.dart` — `ProjectModel`
      (`@JsonSerializable`), maps to/from `Project` entity and the
      `RegistryDatabase` `projects` row. Header + dartdoc.
- [x] 4.2 Run
      `flutter pub run build_runner build --delete-conflicting-outputs`
      to generate `project_model.g.dart`.
- [x] 4.3 `data/repositories/drift_project_repository.dart` —
      `DriftProjectRepository implements ProjectRepository`, backed by
      `RegistryDatabase`. Plain reads/writes only, no validation (per
      Cubit-vs-repository split in `project.md`). Header + dartdoc.
- [x] 4.4 `data/repositories/bundled_baseline_repository.dart` —
      `BundledBaselineRepository implements BaselineRepository`. Reads
      `assets/baseline/<version>/manifest.json` via Flutter's asset
      bundle; lists `<rootPath>/.aion/overrides/` files for
      `readOverrides` (desktop only — returns `[]` when `rootPath` is
      null). Header + dartdoc.
