# 4. **`lib/features/tickets/presentation/screens/ticket_detail_screen.dart`**

— replace the read-only `StatusIndicator(status: ticket.status)` in
the type/status `Row` with a `SelectionMenu<TicketStatus>` whose
`trigger` is that same `StatusIndicator`, `items: TicketStatus.values`,
`itemLabel: (s) => ticketStatusLabel(context, s)`,
`currentValue: ticket.status`, `onSelected` calling
`context.read<TicketsCubit>().changeTicketStatus(ticket, s)`, and
`semanticsLabel: context.l10n.ticketDetailChangeStatus` — exact
mirror of the adjacent `SelectionMenu<TicketType>` wiring (see
`design.md`). `SelectionMenu`, `ticketStatusLabel`, and
`StatusIndicator` are already imported/used in this file; a direct
import of `ticket_status.dart` was needed in addition, since this
edit is the file's first *explicit* reference to the `TicketStatus`
identifier itself (as a type argument and via `TicketStatus.values`)
— Dart imports aren't transitive, so `ticket.status`'s inferred type
didn't require it before. No new public symbols introduced by this
edit, so no new dartdoc needed beyond what already exists on the
surrounding widget tree.
