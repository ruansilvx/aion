from the rendered list internally (matching `MoveToStatusMenu`'s own
filtering and design.md §3.5/§3.6's explicit "lists the other N

generic description suggested — the two ADDED-behavior descriptions
conflicted; the more specific, later Claude Design content wins. T11's
literal `items: TicketPriority.values`/`TicketType.values` (full enum
list) still works correctly since filtering happens inside the widget.

props `trigger`, `items`, `itemLabel`, `currentValue`, `onSelected`,
`semanticsLabel`. Overlay mechanics mirror `MoveToStatusMenu`

trigger in `CompositedTransformTarget` + `FocusableActionDetector` with

trigger. Do **not** modify `MoveToStatusMenu` itself. Dartdoc the
