# **T5 — Fix `ticket_metadata_section_test.dart`'s `MockTicketsCubit`

stub so existing tests keep passing.**
`aion/test/features/tickets/presentation/widgets/ticket_metadata_section_test.dart`:
in the `_wrap` helper, add
`when(() => ticketsCubit.detailTick).thenAnswer((_) =>
const Stream<void>.empty());` before (or alongside) the existing
`whenListen(ticketsCubit, ...)` call. Required because `T3` makes
`TicketMetadataSection` call `.detailTick` unconditionally on every
build, and `MockTicketsCubit` (a `mocktail` `Mock`) throws on any
unstubbed call — every existing test in this file renders
`TicketMetadataSection` through `_wrap`, so without this fix the
entire file fails after T3, not just a new test case.
