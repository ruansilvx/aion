# capture

Lightweight, zero-friction idea capture. Writes a raw idea record from
a single sentence or two — no questions asked, no back-and-forth. The
deliberately narrow counterpart to `brainstorm`, for the moment you have
a thought worth not losing but don't have time for a structured
session right now.

Use it when:

- Something worth pursuing occurs to you mid-task, but exploring it now
  would derail what you're actually doing.
- You want a record that survives to a later session without demanding
  immediate attention.

A captured idea starts in a raw, unexplored state — it's expected to be
picked up and worked through with `brainstorm` (or explored directly)
before it's specific enough to `propose`. Capture is about not losing
the thought, not about fully forming it on the spot.
